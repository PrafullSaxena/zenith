Create three shared components:

**GlassChat.tsx** — Reusable chat interface component used by Cortex QAPanel, DbInspector AskAI, and Launchpad AiAdvisor.
Props interface:
- `messages: Array<{ id: string; role: 'user' | 'assistant'; content: string; citations?: Array<{ label: string; onClick?: () => void }> }>`
- `onSend: (message: string) => void`
- `isStreaming?: boolean`
- `placeholder?: string`
- `className?: string`
- `renderContent?: (content: string) => ReactNode` — optional custom renderer for AI messages (e.g., markdown)

Structure:
- Scrollable message list in a flex-1 container with `overflow-y-auto`
- User messages: right-aligned, wrapped in a `div` with accent-tinted glass styling (`bg-accent/10 border border-accent/20 rounded-2xl rounded-br-sm p-3`). Text is `text-sm text-text-primary`.
- AI messages: left-aligned, wrapped in a `div` with neutral glass styling (`bg-white/[0.03] border border-white/[0.06] rounded-2xl rounded-bl-sm p-3`). If `renderContent` prop provided, use it; otherwise render plain text. Citations render as a flex-wrap row of `GlassBadge variant="accent"` pills below the message content.
- Typing indicator: when `isStreaming` is true and the last message is not from assistant, show a left-aligned glass bubble with 3 `span` dots using staggered `animate-pulse` with increasing `animation-delay` (0ms, 150ms, 300ms). Style dots as `w-2 h-2 rounded-full bg-text-secondary/60`.
- Input area at bottom: `GlassInput` with the placeholder prop, plus a `GlassButton` (icon-only, Send icon from lucide-react) on the right. Wrap in a flex row with gap-2. On Enter keydown or button click, call `onSend` with current input value and clear the input. Disable send button when input is empty or `isStreaming` is true.
- Auto-scroll: use a `useRef` on the message container and `useEffect` to scroll to bottom when messages array length changes.

**GlassTable.tsx** — Glass-styled data table for DbInspector query results and Launchpad estimates.
Props interface:
- `columns: Array<{ key: string; label: string; sortable?: boolean; width?: string }>`
- `data: Array<Record<string, unknown>>`
- `onSort?: (key: string, direction: 'asc' | 'desc') => void`
- `sortKey?: string`
- `sortDirection?: 'asc' | 'desc'`
- `className?: string`
- `emptyMessage?: string`

Structure:
- Outer `GlassCard` wrapper with `overflow-hidden` and no default padding (`className="p-0 overflow-hidden"`)
- `<table className="w-full text-sm">` inside
- `<thead>`: row with `bg-white/[0.03] border-b border-white/[0.06]`. Each `<th>` has `px-4 py-3 text-left text-xs font-medium text-text-secondary uppercase tracking-wider`. If column is sortable, render a clickable header with ChevronUp/ChevronDown icon from lucide-react showing current sort direction. Clicking toggles sort direction and calls `onSort`.
- `<tbody>`: rows with alternating opacity — even rows `bg-white/[0.015]`, odd rows transparent. All rows have `hover:bg-white/[0.04] transition-colors border-b border-white/[0.04]`. Each `<td>` has `px-4 py-3 text-text-primary`.
- If `data` is empty, show a single row spanning all columns with centered `text-text-secondary text-sm` message using `emptyMessage` prop or "No data".

**GlassResizeHandle.tsx** — Draggable vertical resize handle for panel splitting.
Props interface:
- `onResize: (deltaX: number) => void`
- `className?: string`

Structure:
- A `div` with `w-2 cursor-col-resize flex items-center justify-center group` styling
- Inside, a thin vertical bar: `w-0.5 h-8 rounded-full bg-white/10 group-hover:bg-accent/50 transition-colors`
- Use `onMouseDown` to start tracking, `mousemove` on `window` for delta, `mouseup` on `window` to stop. Call `onResize(e.movementX)` on each mousemove while dragging. Set `select-none` on body during drag via `document.body.style.userSelect = 'none'` and restore on mouseup.
