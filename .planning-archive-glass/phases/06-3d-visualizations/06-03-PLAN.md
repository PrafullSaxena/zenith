  <files>src/renderer/src/plugins/db-inspector/SchemaOrb3D.tsx</files>
  <action>
**Create SchemaOrb3D.tsx** — 3D floating table planes with FK connection lines:

1. **Props and data:**
   - Props: `{ tables: TableInfo[], selectedTables: string[], session: ERDiagramSession | null, onTableClick?: (tableName: string) => void }`
   - Filter to selectedTables, cap at 30 tables
   - Extract FK relationships from session data (session has mermaid syntax with FK info, or tables have column FK references — inspect TableInfo type for FK data)

2. **Layout — radial clustering by schema/namespace:**
   - Group tables by schema (if available) or first part of table name (before underscore)
   - Arrange schema groups in a circle on the XZ plane (radius ~20 per group)
   - Within each group, arrange tables in a smaller circle (radius ~8)
   - Y position: slight random variation (-2 to 2) for depth
   - This creates a clustered orbital layout without force simulation (manual placement is more appropriate per research)

3. **3D scene (InnerScene):**
   - Lighting: ambientLight 0.35, pointLight [30, 30, 30] 0.7, pointLight [-20, 20, -20] 0.3
   - Each table: `<mesh>` with `<planeGeometry args={[4, 2.5]}>` and `side={THREE.DoubleSide}`
   - Material: meshStandardMaterial color="#1e293b" emissive="#3b82f6" emissiveIntensity={isHovered ? 0.4 : 0.1} transparent opacity={0.85}
   - Table label: `<Html center distanceFactor={60}>` with glass styling (bg-black/80 backdrop-blur-sm rounded-lg px-2 py-1 text-[10px] text-white) showing table name
   - On hover: increase emissive, show column count in tooltip ("tableName — N columns")
   - On click: call onTableClick(tableName)

4. **FK relationship lines:**
   - For each FK relationship, draw a `<Line>` from drei connecting the two table planes
   - Line color: accent color with transparency ("oklch(0.7 0.15 250 / 0.4)" or similar blue glow)
   - lineWidth: 1.5
   - If a table is hovered, highlight its FK lines by increasing opacity to 0.8

5. **OrbitControls:** autoRotate={!reducedMotion} autoRotateSpeed={0.3}, enablePan, enableZoom, enableRotate, minDistance=10, maxDistance=80

6. **Auto-rotate pause on hover:** Same controlsRef + 3s idle pattern as other scenes.

7. **Reduced motion:** usePrefersReducedMotion disables autoRotate.

8. **Camera:** position [30, 25, 30], fov 50 for a slightly elevated perspective.

9. **Exported component:** Default export with Canvas, transparent bg, touchAction: 'none'.

**Do NOT:**
- Use d3-force-3d (manual radial layout is cleaner for schema visualization per research)
- Render more than 30 tables
- Add zoom buttons
