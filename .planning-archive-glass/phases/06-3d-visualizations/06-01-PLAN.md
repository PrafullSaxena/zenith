- Props: `{ fallback: React.ReactNode, children: React.ReactNode }`
- State: `{ hasError: boolean }`
- `getDerivedStateFromError()` returns `{ hasError: true }`
- `render()` returns `this.props.fallback` when hasError, else `this.props.children`

- Props: `{ fallback: React.ReactNode, children: React.ReactNode, loadingMessage?: string }`

- Export both `Scene3DWrapper` (default) and `Scene3DErrorBoundary` (named) for flexibility

**Create ActivityMesh3D.tsx** following the MindGraph3D pattern:

1. **Data preparation:**
   - Import `useActivityStore` and call `getRecentEntries(50)` for up to 50 recent activity events
   - Map each `ActivityEntry` to a simulation node with position, pluginId, description, timestamp
   - Plugin color mapping: cortex=#06b6d4, db-inspector=#3b82f6, nebula=#ec4899, launchpad=#f59e0b, code-review-bot=#10b981, textcraft=#8b5cf6, fallback=#94a3b8

2. **d3-force-3d simulation:**
   - `forceSimulation(nodes)` with `.force('charge', forceManyBody().strength(-30))`, `.force('center', forceCenter())`, `.alphaDecay(0.02)`
   - No link forces — nodes float freely in a spherical cloud formation
   - Stop simulation in useEffect cleanup: `return () => { sim.stop() }`
   - Use refs (not state) for per-frame position updates to avoid 60fps re-renders (key improvement over MindGraph3D pattern per research anti-patterns)

3. **3D scene (InnerScene component inside Canvas):**
   - Lighting: ambientLight intensity=0.3, pointLight at [80, 80, 80] intensity=0.6
   - Each node: `<mesh>` with `<sphereGeometry args={[radius, 12, 12]}>` where radius scales by recency (newer = larger, range 0.8-2.0)
   - Material: `<meshStandardMaterial color={pluginColor} emissive={pluginColor} emissiveIntensity={isHovered ? 0.7 : 0.2} transparent opacity={0.85} />`
   - Hover: `onPointerOver/Out` sets hoveredId state, shows `<Html center distanceFactor={50}>` tooltip with glass styling (bg-black/80 backdrop-blur-sm rounded-lg px-2 py-1 text-[10px]) showing plugin name and activity description
   - Click: no navigation (Dashboard mesh is ambient, not interactive)
   - OrbitControls: `autoRotate={!reducedMotion} autoRotateSpeed={0.3} enablePan={false} enableZoom enableRotate minDistance={8} maxDistance={40}`

4. **Auto-rotate pause on hover (per CONTEXT.md shared pattern):**
   - controlsRef on OrbitControls
   - pauseAutoRotate callback: sets controlsRef.current.autoRotate = false, clears idle timer, sets new 3s setTimeout to re-enable if !reducedMotion
   - Call pauseAutoRotate on any node onPointerOver

5. **Reduced motion:** Import `usePrefersReducedMotion` from `@renderer/lib/useReducedMotion`. Pass to OrbitControls autoRotate and conditionally disable any pulse/glow animations.

6. **Exported component:** Default export wraps Canvas in a div with `touchAction: 'none'`, Canvas with `camera={{ position: [0, 0, 25], fov: 50 }}` and `gl={{ antialias: true }}` and transparent background.
