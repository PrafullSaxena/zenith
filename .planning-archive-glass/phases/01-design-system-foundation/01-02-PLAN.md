<objective>
Create the centralized motion variants module at lib/motion.ts and relocate the usePrefersReducedMotion hook to the shared lib/ directory. This gives every future component a single import path for consistent animations.

Purpose: Without centralized motion variants, every component defines its own animation configs with inconsistent timing/easing. This module ensures all animations match the "snappy, professional, not bouncy" feel specified in the design system.

Output: lib/motion.ts (variant objects + reduced-motion helper), lib/useReducedMotion.ts (shared hook location).
</objective>
