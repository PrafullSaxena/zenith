    **Tabs (COMP-05) — Animated indicator bar:**

    First, try to install from Animate-UI:
    ```bash
    npx pnpm dlx animate-ui@latest add tabs --yes --overwrite 2>/dev/null
    ```

    If the Animate-UI CLI works and generates a tabs component with animation, customize it with zenith tokens. If it fails or produces something incompatible, build manually:

    Create tabs.tsx based on Radix Tabs primitive (@radix-ui/react-tabs) with a framer-motion animated indicator. The key feature is a layout-animated indicator bar that slides between tabs.

    Structure:
    - `Tabs` — root wrapper (Radix Tabs.Root)
    - `TabsList` — container with `bg-secondary rounded-xl p-1` styling
    - `TabsTrigger` — individual tab with relative positioning. Active state: `text-foreground font-medium`. Inactive: `text-muted-foreground`. Each trigger should contain a framer-motion `layoutId` element for the animated background indicator.
    - `TabsContent` — content panel

    The animated indicator pattern:
    ```tsx
    // Inside TabsTrigger, when active:
    <motion.span
      layoutId="tab-indicator"
      className="absolute inset-0 bg-card rounded-lg shadow-sm"
      style={{ zIndex: -1 }}
      transition={{ type: "spring", damping: 20, stiffness: 90, duration: 0.25 }}
    />
    ```

    This creates the sliding tab indicator effect. The layoutId must be scoped per Tabs instance — use React context or a unique ID prop on TabsList to prevent cross-component conflicts. Consider using `useId()` to generate the layoutId prefix automatically.

    Ensure all Radix a11y attributes are preserved (role="tablist", role="tab", aria-selected, etc.).

    **Dialog (COMP-07) — Scale + fade animation:**

    First, try Animate-UI:
    ```bash
    npx pnpm dlx animate-ui@latest add dialog --yes --overwrite 2>/dev/null
    ```

    If that fails, build from shadcn Dialog + framer-motion:
    ```bash
    npx pnpm dlx shadcn@latest add dialog --yes --overwrite
    ```

    Then wrap DialogContent with framer-motion animations. Per MASTER.md:
    - Overlay: `bg-black/60 backdrop-blur-sm` with fade in/out
    - Content: `bg-card border border-border rounded-[28px] p-6 shadow-2xl`
    - Animation: scale from 0.95 to 1.0 + opacity 0 to 1, with spring(damping:20, stiffness:90)
    - Duration: ~200ms enter, ~140ms exit (exit is 70% of enter per MASTER.md rule)

    Use framer-motion's AnimatePresence for exit animations. The DialogContent should be wrapped in motion.div:
    ```tsx
    <motion.div
      initial={{ opacity: 0, scale: 0.95 }}
      animate={{ opacity: 1, scale: 1 }}
      exit={{ opacity: 0, scale: 0.95 }}
      transition={{ type: "spring", damping: 20, stiffness: 90 }}
    >
    ```

    Ensure focus trapping and Escape-to-close from Radix are preserved. Export: Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter, DialogClose.
  </action>
