Create `src/renderer/src/components/shared/content-renderer.tsx`. Reference the existing `MarkdownRenderer.tsx` for patterns but build fresh with the new design spec.

**Props interface:**
```ts
interface ContentRendererProps {
  content: string
  format?: 'markdown' | 'raw'  // default 'markdown'
  isStreaming?: boolean
  actions?: ('copy-raw' | 'copy-md' | 'export-pdf' | 'save-as-note' | 'run-sql')[]
  onAction?: (action: string, context: { content: string; selection?: string }) => void
  citationLinks?: { label: string; onClick: () => void }[]
  collapsible?: boolean
  className?: string
}
```

**Implementation:**

1. **Markdown parsing**: Use a custom parser approach (NOT react-markdown which is heavy). Parse markdown content into an AST-like structure using a simple state machine or regex-based parser. Alternatively, check if the existing MarkdownRenderer.tsx already has a good parsing approach and adapt it.

   RECOMMENDED APPROACH: Use the existing `MarkdownRenderer.tsx` as the base. Read it thoroughly. It likely already handles headings, bold/italic, code blocks, tables, lists, etc. Migrate its logic, replacing Glass styling with zenith tokens.

   If the existing renderer uses a library (marked, react-markdown, etc.), continue using it. If it's custom regex parsing, keep that approach.

2. **Code blocks with syntax highlighting**: For fenced code blocks (```language ... ```):
   - Use `lowlight` (already installed) for syntax highlighting: `import { common, createLowlight } from 'lowlight'`
   - Render highlighted HTML in a `pre > code` block with:
     - Container: `relative rounded-xl bg-secondary/50 border border-border overflow-hidden my-3`
     - Header bar: `flex items-center justify-between px-4 py-2 bg-secondary border-b border-border text-xs text-muted-foreground` showing language name + Copy button
     - Code area: `p-4 overflow-x-auto text-sm font-mono` with highlighted spans
   - Copy button: shadcn `Button` variant="ghost" size="icon-xs" with `Copy`/`Check` icon toggle on click
   - If `actions` includes `'run-sql'` AND the code block language is `sql`, add a "Run" button next to Copy

3. **Mermaid diagrams**: For ```mermaid ... ``` code blocks:
   - Lazy-load mermaid: `const mermaid = await import('mermaid')` inside a useEffect or on first encounter
   - Initialize with dark theme: `mermaid.initialize({ theme: 'dark', themeVariables: { primaryColor: '#7c3aed', ... } })`
   - Render to SVG using `mermaid.render('mermaid-{uniqueId}', content)`
   - Display SVG in a `div` with `flex justify-center p-4 bg-secondary/30 rounded-xl border border-border my-3`
   - If mermaid fails to parse, show the raw content in a code block with an error message

4. **Tables**: Render markdown tables as styled HTML tables:
   - `table`: `w-full text-sm border-collapse my-3`
   - `thead`: `bg-secondary`
   - `th`: `px-4 py-2 text-left font-medium text-muted-foreground border-b border-border`
   - `td`: `px-4 py-2 border-b border-border/50`

5. **Streaming indicator**: When `isStreaming` is true:
   - Append a `Skeleton` shimmer block after the last rendered content: `h-4 w-32 rounded animate-pulse` using shadcn Skeleton
   - Add a blinking cursor character at the very end of rendered text

6. **Action bar**: If `actions` array is provided, render a sticky bottom bar:
   - Container: `flex items-center gap-2 pt-3 border-t border-border mt-4`
   - Map each action to a `Button` (variant="ghost", size="sm"):
     - `copy-raw`: Copy icon + "Copy" -- copies raw content to clipboard
     - `copy-md`: FileText icon + "Copy Markdown" -- copies content as markdown
     - `export-pdf`: FileDown icon + "Export PDF" -- calls `onAction('export-pdf', { content })`
     - `save-as-note`: BookOpen icon + "Save as Note" -- calls `onAction('save-as-note', { content })`
     - `run-sql`: Play icon + "Run SQL" -- calls `onAction('run-sql', { content })` (this is a global action, distinct from per-block run buttons)
   - On copy actions, show toast "Copied to clipboard" via sonner

7. **Citation links**: If `citationLinks` provided, render at the bottom before action bar:
   - Row of clickable links: `text-primary text-sm hover:underline cursor-pointer` with a footnote icon

8. **Collapsible mode**: When `collapsible` is true:
   - Parse `##` headings as section boundaries
   - Wrap each section in shadcn `Accordion` / `AccordionItem` with the heading as trigger
   - First section expanded by default, rest collapsed

9. **Raw format**: When `format === 'raw'`, render content in a `pre` block with `whitespace-pre-wrap font-mono text-sm`.

10. **General typography**: Apply prose-like styling to rendered content:
    - Headings: `text-foreground font-semibold` with appropriate sizes (h1: text-2xl, h2: text-xl, h3: text-lg)
    - Paragraphs: `text-foreground/90 leading-relaxed my-2`
    - Bold/italic: standard styling
    - Inline code: `bg-secondary px-1.5 py-0.5 rounded text-sm font-mono text-primary`
    - Blockquotes: `border-l-2 border-primary/50 pl-4 italic text-muted-foreground my-3`
    - Lists: proper indentation with `list-disc` / `list-decimal`

Create `src/renderer/src/components/shared/chat-interface.tsx`. Reference the existing `GlassChat.tsx` for patterns but build fresh with the new design spec.

**Types:**
```ts
interface ChatMessage {
  id: string
  role: 'user' | 'assistant'
  content: string
  citations?: { label: string; onClick: () => void }[]
  actions?: { label: string; icon?: LucideIcon; onClick: () => void }[]
  timestamp?: Date
}

interface ChatInterfaceProps {
  messages: ChatMessage[]
  onSend: (message: string) => void
  isStreaming?: boolean
  placeholder?: string  // default "Type a message..."
  suggestedQuestions?: string[]
  renderActions?: (message: ChatMessage) => React.ReactNode
  className?: string
}
```

**Implementation:**

1. **Layout**: Flex column filling parent height:
   - Messages area: `flex-1 overflow-y-auto` with `ScrollArea` from shadcn
   - Input area: `flex-shrink-0` at bottom

2. **Messages rendering**: Map over `messages` array:
   - **User messages**: Right-aligned (`flex justify-end`), primary tint background (`bg-primary/15 text-foreground rounded-2xl rounded-br-md px-4 py-2.5 max-w-[80%]`), plain text content
   - **Assistant messages**: Left-aligned (`flex justify-start`), rendered in a `Card` wrapper (`rounded-2xl rounded-bl-md p-4 max-w-[85%] border border-border`), content rendered via `ContentRenderer` component imported from `@renderer/components/shared/content-renderer`
   - Each message: flex row with appropriate alignment, `mb-4` spacing
   - Pass `citationLinks` from `message.citations` to `ContentRenderer`
   - If `message.actions`, render action buttons below the message content

3. **renderActions**: If provided, call `renderActions(message)` for each assistant message and render the result below the `ContentRenderer` output. This allows plugins to add custom action buttons per message (e.g., "Run SQL" for DB Inspector).

4. **Streaming indicator**: When `isStreaming` is true:
   - Pass `isStreaming` to the last assistant message's `ContentRenderer`
   - Below the last message, show a typing indicator: 3 dots with staggered animation using framer-motion:
     ```tsx
     <div className="flex gap-1.5 px-4 py-3">
       {[0, 1, 2].map((i) => (
         <motion.div
           key={i}
           className="size-2 rounded-full bg-muted-foreground"
           animate={{ opacity: [0.3, 1, 0.3] }}
           transition={{ duration: 1, repeat: Infinity, delay: i * 0.2 }}
         />
       ))}
     </div>
     ```

5. **Auto-scroll**: Use a `useEffect` that scrolls to bottom when `messages.length` changes or `isStreaming` changes. Use a ref on a sentinel div at the bottom: `ref.current?.scrollIntoView({ behavior: 'smooth' })`.

6. **Suggested questions**: When `suggestedQuestions` is provided AND `messages.length === 0` (empty chat):
   - Render centered in the messages area
   - Each suggestion: `Button` variant="outline" with `rounded-full` that calls `onSend(question)` on click
   - Layout: `flex flex-wrap gap-2 justify-center p-4`
   - Subtle label above: "Suggested questions" in text-sm text-muted-foreground

7. **Input area**: At the bottom:
   - Container: `flex items-end gap-2 p-4 border-t border-border`
   - Text input: shadcn `Textarea` (NOT Input -- allows multi-line) with `placeholder`, auto-resize behavior (min 1 row, max 4 rows), `rounded-2xl bg-card border border-border px-4 py-3`
   - Auto-resize: Use a `useEffect` that sets `textarea.style.height = 'auto'` then `textarea.style.height = textarea.scrollHeight + 'px'` on value change, capped at ~120px
   - Send button: shadcn `Button` with `Send` icon (lucide), `size="icon"`, disabled when input is empty or `isStreaming`
   - Submit on Enter (without Shift). Shift+Enter for newline. Prevent submit when empty or streaming.

8. **Empty state**: When no messages and no suggested questions, show a subtle centered message: "Start a conversation" in text-muted-foreground.
