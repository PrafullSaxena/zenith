Create `src/renderer/src/components/shared/data-table.tsx`.

**Types:**
```ts
interface Column<T = Record<string, unknown>> {
  key: string
  label: string
  render?: (value: unknown, row: T) => React.ReactNode
  sortable?: boolean
  width?: string  // CSS width value
}

interface DataTableProps<T = Record<string, unknown>> {
  columns: Column<T>[]
  data: T[]
  sortable?: boolean  // global sortable toggle
  paginated?: boolean
  pageSize?: number  // default 10
  onRowClick?: (row: T) => void
  emptyMessage?: string  // default "No data"
  virtualScroll?: boolean  // enable for >100 rows
  className?: string
}
```

**Implementation:**
1. **State**: `sortKey: string | null`, `sortDir: 'asc' | 'desc'`, `currentPage: number`
2. **Sorting**: When a sortable column header is clicked, toggle sort direction. Sort data with `useMemo` using `Array.from(data).sort(...)`. Use `ArrowUpDown`, `ArrowUp`, `ArrowDown` icons from lucide-react in headers.
3. **Pagination**: If `paginated`, slice sorted data by `currentPage * pageSize`. Render pagination controls below table: "Page X of Y" text, Previous/Next buttons using shadcn `Button` (variant="ghost", size="sm"). Disable at boundaries.
4. **Table structure**: Use plain HTML `table` with Tailwind (NOT a shadcn Table -- keep it simple):
   - `<table className="w-full text-sm">`
   - `<thead>`: `bg-secondary` header row, `text-left text-muted-foreground font-medium px-4 py-3` cells, `border-b border-border`
   - `<tbody>`: rows with `border-b border-border/50 hover:bg-secondary/50 transition-colors cursor-pointer` (if onRowClick). Cells: `px-4 py-3`
   - Column widths via `style={{ width: column.width }}` on th/td
5. **Virtual scroll**: When `virtualScroll` is true, use `@tanstack/react-virtual` `useVirtualizer`:
   - Wrap tbody content in a container with `position: relative` and `height: totalSize`
   - Each row uses `position: absolute`, `transform: translateY(start)`
   - `estimateSize: () => 48` (standard row height)
   - Container has `max-h-[600px] overflow-y-auto` with shadcn `ScrollArea` or native scroll
   - When virtualScroll is false, render all rows normally
6. **Cell expansion**: If any cell content is truncated (text longer than 100 chars), show a small expand icon on hover. Clicking opens a `Dialog` with full content rendered in a `ScrollArea`.
7. **Empty state**: When `data.length === 0`, render centered `emptyMessage` text in muted-foreground.
8. **Custom rendering**: If `column.render` is provided, call it with `(row[column.key], row)`. Otherwise, render `String(row[column.key])` with `truncate` class.

**Export:** Named export `DataTable` and `Column` type.

Create `src/renderer/src/components/shared/history-list.tsx`.

**Types:**
```ts
interface HistoryEntry {
  id: string
  title: string
  subtitle?: string
  timestamp: string | Date
  type?: string  // for type badge
  badge?: { label: string; variant?: string }
  preview?: string
}

interface HistoryFilter {
  key: string
  label: string
  options: { value: string; label: string }[]
}

interface HistoryListProps {
  entries: HistoryEntry[]
  onRestore: (entry: HistoryEntry) => void
  onDelete?: (entry: HistoryEntry) => void
  renderEntry?: (entry: HistoryEntry) => React.ReactNode
  emptyMessage?: string  // default "No history entries"
  filters?: HistoryFilter[]
  className?: string
}
```

**Implementation:**
1. **Filters**: If `filters` provided, render a row of shadcn `Select` components at the top. Each filter controls a `useState` for its active value. Filter entries with `useMemo` based on active filter values matching `entry[filter.key]`.
2. **Entry cards**: For each filtered entry, render a `Card` with:
   - `CardContent` with `p-4` (compact padding)
   - Top row: `title` (font-medium) + optional `Badge` for `type` or `badge` field + relative timestamp (right-aligned, text-sm text-muted-foreground)
   - Format timestamp: Use `new Date(timestamp)` and compute relative time (e.g., "2h ago", "3d ago", "Jan 15"). Implement a simple `formatRelativeTime` helper inside the file.
   - Middle: `subtitle` or `preview` in text-sm text-muted-foreground, truncated to 2 lines
   - Bottom row: Action buttons -- "Restore" `Button` (variant="ghost", size="sm") calls `onRestore(entry)`, optional "Delete" `Button` (variant="ghost", size="sm", text-destructive) calls `onDelete(entry)` with `AlertDialog` confirmation
3. **Custom rendering**: If `renderEntry` provided, use it instead of default card layout.
4. **Empty state**: When no entries (after filtering), show centered `emptyMessage` in muted-foreground.
5. **Scroll**: Wrap list in shadcn `ScrollArea` with `max-h-[calc(100vh-200px)]`.
6. **Spacing**: `flex flex-col gap-2` between entry cards.

**Imports:** Card from ui/card, Badge from ui/badge, Button from ui/button, Select from ui/select, AlertDialog from ui/alert-dialog, ScrollArea from ui/scroll-area.
