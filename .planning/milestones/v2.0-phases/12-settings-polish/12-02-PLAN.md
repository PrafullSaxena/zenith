  <name>Task 1: Create SyncStatusBadge component with popover</name>
  <files>
    src/renderer/src/plugins/launchpad/SyncStatusBadge.tsx
  </files>
  <action>
    Create `SyncStatusBadge.tsx` -- a self-contained component that:

    **Badge display:**
    - Renders a small pill: colored dot (h-2 w-2 rounded-full) + text label.
    - Badge states with colors:
      - "Live" (green dot, green/10 bg) -- all providers with keys are recently synced
      - "Partial" (amber dot, amber/10 bg) -- at least one provider synced but another is stale or has no key
      - "Cached" (gray dot, gray/10 bg) -- using seeded data, no sync has ever completed
      - "Stale" (red dot, red/10 bg) -- all providers are past 2x sync frequency threshold
    - Pill styling: `rounded-lg px-2 py-0.5 text-xs font-medium cursor-pointer` with subtle border (border-white/6). Subtle enough to not compete with header tabs but visible enough for stale state.

    **Aggregation logic:**
    - Fetch `window.api.launchpad.getSyncStatus()` and `window.api.launchpad.getCredentialStatus()` on mount.
    - Read sync frequency from settings store (`plugins.launchpad.syncFrequency`, default "daily").
    - Convert frequency to ms: 6h=21600000, 12h=43200000, daily=86400000, weekly=604800000, manual=Infinity.
    - Stale threshold = 2x frequency ms.
    - For each provider: classify as "live" (synced within threshold), "stale" (synced but past threshold), "noKey" (gcp without key), "never" (never synced).
    - Aggregate: all live -> "Live"; some live + some not -> "Partial"; all never synced -> "Cached"; all stale -> "Stale".

    **Popover (on click):**
    - Use the existing Popover/PopoverTrigger/PopoverContent components from `@renderer/components/ui/popover`.
    - Content: a compact card with per-provider rows (AWS, GCP, Azure). Each row: provider name, colored status dot + label (same as Settings panel), relative timestamp.
    - Footer: a "Manage in Settings" link. On click: navigate to `/settings?tab=launchpad` using `useNavigate()` from react-router-dom. Close popover.
    - Popover positioning: `side="bottom" align="end"` to drop down from the header badge.

    **Live refresh:**
    - Register `window.api.launchpad.onSyncComplete` listener in a `useEffect`. On each sync complete event, re-fetch sync status and credential status to update badge. Return unsubscribe on cleanup.
    - This ensures the badge updates immediately after a background sync or manual sync from settings.

    **Reuse `formatRelativeTime` from LaunchpadSettings.tsx:**
    - Extract the `formatRelativeTime` helper into a shared location OR duplicate it inline (small function, ~15 lines). Prefer extracting to `src/renderer/src/plugins/launchpad/utils.ts` if the function was created inline in Plan 01 -- read LaunchpadSettings.tsx first to check. If it is inline there, extract to a shared `utils.ts` and update both files to import from it.
