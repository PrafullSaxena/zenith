**src/renderer/src/plugins/code-review-bot/PRDiffView.tsx:**

Props: `{ diffFiles: DiffFile[]; reviewComments: ReviewComment[]; onCommentClick?: (comment: ReviewComment) => void }`

- Renders a file-by-file diff viewer (NOT side-by-side -- unified diff view)
- For each DiffFile: collapsible file header showing `file.to` path with additions/deletions count badges (`+{additions}` in green, `-{deletions}` in red)
- For each DiffChunk: render the chunk header (@@...@@ line) in text-text-secondary
- For each DiffChange:
  - `type === 'add'`: green-tinted background (`bg-green-950/30`), `+` prefix, line number from `ln`
  - `type === 'del'`: red-tinted background (`bg-red-950/30`), `-` prefix, line number from `ln1`
  - `type === 'normal'`: default bg, space prefix, line number from `ln2`
  - Monospace font (`font-mono text-sm`)
  - Line numbers in fixed-width column (text-text-secondary, text-xs)
- **Inline AI comments:** After each diff line, if a ReviewComment exists for that file and line number, render an inline comment card below the line:
  - Comment card has bg-surface-elevated, left border colored by severity (red=critical, yellow=warning, cyan=suggestion)
  - Shows severity badge + comment text
  - "Post to Bitbucket" button if not yet posted (calls onCommentClick)
- Horizontal scroll for long lines with `overflow-x-auto`
- File sections default to expanded; user can collapse

**src/renderer/src/plugins/code-review-bot/ReviewPanel.tsx:**

Props: `{ session: ReviewSession | null; onStart: () => void; onCancel: () => void; onPostAll: () => void; isConnected: boolean; hasAgent: boolean }`

- **No active review (session === null):** Show "Start Review" button (disabled if !isConnected or !hasAgent). If not connected, show "Connect to Bitbucket first" hint. If no agent, show "Configure AI agent in settings" hint.
- **Streaming (session.status === 'streaming'):** Show animated streaming indicator (pulsing cyan dot). Display accumulated rawText in a monospace scrollable area, auto-scrolling to bottom. "Cancel Review" button.
- **Complete (session.status === 'complete'):** Show comment summary: "{N} comments found ({criticals} critical, {warnings} warnings, {suggestions} suggestions)". "Post All Comments" button. List individual comments with checkboxes to select which to post.
- **Error (session.status === 'error'):** Show error message in red. "Retry" button (calls onStart).
- **Cancelled:** Show "Review cancelled" message. "Start New Review" button.
