- `getPricingDb(): Database.Database` — returns the singleton instance; throws if called before init

DB path: `path.join(app.getPath('userData'), 'pricing.db')`

Schema to execute (run each as `db.exec()`):

```sql
CREATE TABLE IF NOT EXISTS pricing_services (
  id TEXT NOT NULL, provider TEXT NOT NULL, category TEXT NOT NULL,
  name TEXT NOT NULL, description TEXT, config_schema TEXT NOT NULL,
  equivalence_id TEXT, updated_at INTEGER NOT NULL,
  PRIMARY KEY (id, provider)
);
CREATE TABLE IF NOT EXISTS pricing_rates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  service_id TEXT NOT NULL, provider TEXT NOT NULL, region TEXT NOT NULL,
  rate_key TEXT NOT NULL, value REAL NOT NULL, unit TEXT, tier TEXT,
  fetched_at INTEGER NOT NULL,
  UNIQUE(service_id, provider, region, rate_key, tier)
);
CREATE INDEX IF NOT EXISTS idx_rates_lookup ON pricing_rates(provider, region, service_id);
CREATE INDEX IF NOT EXISTS idx_rates_service ON pricing_rates(service_id, provider);
CREATE TABLE IF NOT EXISTS pricing_regions (
  provider TEXT NOT NULL, region_id TEXT NOT NULL, display_name TEXT NOT NULL,
  PRIMARY KEY (provider, region_id)
);
CREATE TABLE IF NOT EXISTS pricing_sync_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT, provider TEXT NOT NULL,
  status TEXT NOT NULL, services_updated INTEGER, error TEXT,
  started_at INTEGER NOT NULL, completed_at INTEGER
);
```

Module-level variable: `let db: Database.Database | null = null`

`initPricingDb()`:
1. Construct dbPath
2. `db = new Database(dbPath)`
3. `db.pragma('journal_mode = WAL')`
4. Run all CREATE TABLE IF NOT EXISTS and CREATE INDEX IF NOT EXISTS statements via `db.exec()`

`getPricingDb()`:
1. If `db === null` throw new Error('PricingDb not initialized — call initPricingDb() first')

<task type="auto">
  <name>Task 2: Create pricing-repository.ts — PricingRepository class</name>
  <files>src/main/pricing/pricing-repository.ts</files>
  <action>
Create `src/main/pricing/pricing-repository.ts`. This class is the only way other main-process code should query pricing data.

Import `getPricingDb` and `RateRow` from `./pricing-db`.
Import types: `CloudProvider` = `'aws' | 'gcp' | 'azure'` (define locally — do NOT import from renderer).

Define these local interfaces (export all):

```typescript
export type CloudProvider = 'aws' | 'gcp' | 'azure'

export interface Region {
  regionId: string
  displayName: string
}

export interface ServiceEntry {
  id: string
  provider: CloudProvider
  category: string
  name: string
  description: string | null
  configSchema: string  // raw JSON string
  equivalenceId: string | null
  updatedAt: number
}

export interface ServiceCategory {
  id: string
  name: string
  services: ServiceEntry[]
}

export type RateMap = Record<string, Record<string, number>>
// { [serviceId]: { [rateKey]: value } }

export interface SyncStatus {
  provider: CloudProvider
  lastSyncAt: number | null
  status: string | null
  servicesUpdated: number | null
  error: string | null
}
```

Implement `PricingRepository` class with these methods (use prepared statements via `db.prepare()`):

**`getCatalog(provider: CloudProvider): ServiceCategory[]`**
- Query: `SELECT * FROM pricing_services WHERE provider = ? ORDER BY category, name`
- Group rows by category into ServiceCategory[]
- Each category: derive `id` from first word of category name lowercased, `name` = category string
- Return array of ServiceCategory with services array

**`getRates(serviceIds: string[], provider: CloudProvider, region: string): RateMap`**
- If serviceIds is empty return {}
- Query uses `WHERE provider = ? AND region = ? AND service_id IN (...)` — build placeholders dynamically: `serviceIds.map(() => '?').join(',')`
- Build RateMap: `result[row.service_id][row.rate_key] = row.value`
- Return RateMap

**`getRegions(provider: CloudProvider): Region[]`**
- Query: `SELECT region_id, display_name FROM pricing_regions WHERE provider = ? ORDER BY region_id`
- Return `Region[]`

**`getSyncStatus(provider: CloudProvider): SyncStatus`**
- Query: `SELECT * FROM pricing_sync_log WHERE provider = ? ORDER BY started_at DESC LIMIT 1`
- If no row: return `{ provider, lastSyncAt: null, status: null, servicesUpdated: null, error: null }`
- Else map row fields to SyncStatus

**`upsertRates(rates: RateRow[]): void`**
- Prepare: `INSERT OR REPLACE INTO pricing_rates (service_id, provider, region, rate_key, value, unit, tier, fetched_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?)`
- Wrap in transaction: `const insertMany = db.transaction((rows: RateRow[]) => { ... })`
- Call insertMany(rates)

**`upsertService(service: Omit<ServiceEntry, never>): void`**
- Prepare: `INSERT OR REPLACE INTO pricing_services (id, provider, category, name, description, config_schema, equivalence_id, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?)`

**`upsertRegion(provider: CloudProvider, regionId: string, displayName: string): void`**
- Prepare: `INSERT OR REPLACE INTO pricing_regions (provider, region_id, display_name) VALUES (?, ?, ?)`

**`isSeeded(provider: CloudProvider): boolean`**
- Query: `SELECT COUNT(*) as count FROM pricing_services WHERE provider = ?`
- Return count > 0

**`seedFromFallback(): void`**
- This method intentionally left as a stub — implementation is in seed.ts which calls this repository. Add comment: `// Called by seed.ts — see src/main/pricing/seed.ts`
- The method body should be empty (no-op stub) — seed.ts will call upsertService/upsertRegion/upsertRates directly

Export a singleton: `export const pricingRepository = new PricingRepository()`

Import `safeStorage` from 'electron' and `Store` from 'electron-store'.

The four credential keys used by Launchpad (document as constants):
```typescript
export const CRED_GCP_API_KEY = 'launchpad.credentials.gcp.apiKey'
export const CRED_AWS_ACCESS_KEY_ID = 'launchpad.credentials.aws.accessKeyId'
export const CRED_AWS_SECRET_ACCESS_KEY = 'launchpad.credentials.aws.secretAccessKey'
export const CRED_GCP_BILLING_ACCOUNT_ID = 'launchpad.credentials.gcp.billingAccountId'
```

Export four functions:

**`saveCredential(key: string, value: string): void`**
- Check `safeStorage.isEncryptionAvailable()` — throw Error('safeStorage not available') if false
- `const encrypted = safeStorage.encryptString(value)`
- `launchpadCredStore.set(key, encrypted.toString('base64'))`

**`getCredential(key: string): string | null`**
- If `!launchpadCredStore.has(key)` return null
- `const encoded = launchpadCredStore.get(key) as string`
- Return `safeStorage.decryptString(Buffer.from(encoded, 'base64'))`

**`hasCredential(key: string): boolean`**
- Return `launchpadCredStore.has(key)`

**`deleteCredential(key: string): void`**
- `launchpadCredStore.delete(key)`

Note: Do NOT re-export or share the `credentialsStore` from ipc-handlers.ts. This is a separate store file (`zenith-launchpad-credentials`) to keep Launchpad credentials isolated from other plugin credentials.
