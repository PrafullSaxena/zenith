Create `src/main/pricing/seed.ts`. This file is the bridge between the existing renderer-side hardcoded TS catalogs and the new SQLite DB. It runs only when `pricingRepository.isSeeded(provider)` returns false for any provider.

Imports needed:
```typescript
import { pricingRepository } from './pricing-repository'
import { AWS_CATALOG, AWS_REGIONS } from '../../renderer/src/data/cloud-pricing/aws'
import { GCP_CATALOG, GCP_REGIONS } from '../../renderer/src/data/cloud-pricing/gcp'
import { AZURE_CATALOG, AZURE_REGIONS } from '../../renderer/src/data/cloud-pricing/azure'
import type { CloudProvider } from './pricing-repository'
import type { ProviderCatalog, SelectOption } from '../../renderer/src/data/cloud-pricing/types'
```

Verify the actual export names by checking `src/renderer/src/data/cloud-pricing/aws.ts`, `gcp.ts`, `azure.ts` — use the real export names (may differ from above).

Implement helper `seedProvider(catalog: ProviderCatalog, regions: SelectOption[], provider: CloudProvider): void`:
1. Skip if `pricingRepository.isSeeded(provider)` returns true
2. For each region in regions:
   - Call `pricingRepository.upsertRegion(provider, region.value, region.label)`
3. For each category in `catalog.categories`:
   - For each service in `category.services`:
     - Build `ServiceEntry`: `{ id: service.id, provider, category: category.name, name: service.name, description: service.description ?? null, configSchema: JSON.stringify(service.configSchema), equivalenceId: null, updatedAt: Date.now() }`
     - Call `pricingRepository.upsertService(serviceEntry)`
     - Extract rates from configSchema options into RateRow[]:
       - For each field in `service.configSchema`:
         - If field is `type: 'select'` and options have `pricePerHour`, `pricePerGb`, or other numeric price properties:
           - For each option that has a price property: create a RateRow with `{ service_id: service.id, provider, region: 'us-east-1' (for AWS), rate_key: \`${field_name}.${option.value}\`, value: option.priceProperty, unit: 'USD', tier: 'onDemand', fetched_at: Date.now() }`
         - Use the default/first region as the seed region for rate rows
     - If any rates were extracted, call `pricingRepository.upsertRates(rates)`

Note on rate extraction: The existing catalogs embed prices in configSchema option objects (e.g., `pricePerHour: 0.0104`). The seeder should iterate over configSchema fields, find select fields with options that contain numeric price properties, and normalize those into RateRow records. Use region `us-east-1` for AWS, `us-central1` for GCP, `eastus` for Azure as the canonical seed region.

Export `seedPricingDb(): void`:
```typescript
export function seedPricingDb(): void {
  seedProvider(AWS_CATALOG, AWS_REGIONS, 'aws')
  seedProvider(GCP_CATALOG, GCP_REGIONS, 'gcp')
  seedProvider(AZURE_CATALOG, AZURE_REGIONS, 'azure')
}
```

This function is idempotent — safe to call on every app startup. The isSeeded() check inside seedProvider ensures no double-write.

**3. Three new IPC handlers** inside `registerIpcHandlers()`, after the existing launchpad:exportPdf handler:

**`launchpad:getCatalog`**:
```typescript
ipcMain.handle('launchpad:getCatalog', (_event, provider: string) => {
  if (!['aws', 'gcp', 'azure'].includes(provider)) {
    throw new Error(`Invalid provider: ${provider}`)
  }
  return pricingRepository.getCatalog(provider as 'aws' | 'gcp' | 'azure')
})
```

**`launchpad:getPricing`**:
```typescript
ipcMain.handle(
  'launchpad:getPricing',
  (_event, args: { provider: string; region: string; serviceIds: string[] }) => {
    if (!['aws', 'gcp', 'azure'].includes(args.provider)) {
      throw new Error(`Invalid provider: ${args.provider}`)
    }
    if (typeof args.region !== 'string' || !Array.isArray(args.serviceIds)) {
      throw new Error('Invalid arguments: region must be string, serviceIds must be array')
    }
    return pricingRepository.getRates(
      args.serviceIds,
      args.provider as 'aws' | 'gcp' | 'azure',
      args.region
    )
  }
)
```

**`launchpad:saveCredentials`**:
```typescript
ipcMain.handle(
  'launchpad:saveCredentials',
  (_event, credentials: { gcpApiKey?: string; awsAccessKeyId?: string; awsSecretAccessKey?: string; gcpBillingAccountId?: string }) => {
    if (credentials.gcpApiKey !== undefined) {
      saveCredential(CRED_GCP_API_KEY, credentials.gcpApiKey)
    }
    if (credentials.awsAccessKeyId !== undefined) {
      saveCredential(CRED_AWS_ACCESS_KEY_ID, credentials.awsAccessKeyId)
    }
    if (credentials.awsSecretAccessKey !== undefined) {
      saveCredential(CRED_AWS_SECRET_ACCESS_KEY, credentials.awsSecretAccessKey)
    }
    if (credentials.gcpBillingAccountId !== undefined) {
      saveCredential(CRED_GCP_BILLING_ACCOUNT_ID, credentials.gcpBillingAccountId)
    }
    return { saved: true }
  }
)
```

Important: The module-level `initPricingDb()` + `seedPricingDb()` call must be at module scope (executed when the module loads), NOT inside `registerIpcHandlers()`. This ensures DB is ready before any handler could be called.
