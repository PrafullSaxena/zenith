    ```typescript

      serviceId: string,
      config: ResourceConfig,
      rates: ServiceRates,
    ```

    In the function body, replace every hardcoded price constant with a rate lookup from `rates`:
    - `rates['pricePerHour'] ?? 0` instead of `0.023`
    - `rates['pricePerGb'] ?? 0` instead of `0.023`
    - `rates['requestPricePerMillion'] ?? 0` instead of `0.20`
    - etc.

    The lookup convention: rate_key names must match the `rate_key` column values in `pricing_rates` DB table. Use these keys (consistent with what seed.ts writes from pricePerHour in catalog options):

    - Serverless functions: `pricePerMillionRequests`, `pricePerGbSecond`
    - Managed DB: read from SelectOption.pricePerHour as primary (same as compute)
    - Block storage: `pricePerGb`
    - Data transfer / CDN: `pricePerGb`
    - API Gateway: `pricePerMillionRequests`

    IMPORTANT: For services where the existing code already reads price from a SelectOption (pricePerHour on the config value) — keep that as the primary read path. The `findService()` helper that looked up names from the catalog is also removed from the public calculateTotalCost — instead, callers must pass a `serviceName` alongside each selection, OR calculateTotalCost uses `serviceId` as the display name fallback.
