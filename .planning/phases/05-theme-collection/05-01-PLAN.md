<task type="auto">
  <name>Task 2: Create 6 new theme CSS blocks</name>
  <files>src/renderer/src/assets/main.css</files>
  <action>
  Add 6 new [data-theme] blocks to main.css, after the existing theme blocks. Each block defines all 21 CSS custom properties. Follow the OKLch hue guide from 05-RESEARCH.md and the palette descriptions from 05-CONTEXT.md.

  Design philosophy: Themes optimized for high-volume reading and writing — no eye strain, controlled saturation, sufficient contrast (WCAG AA 4.5:1 for text), glass compatibility. Keep backgrounds at oklch lightness 10-16%, accents at lightness 60-75%.

  **Midnight Bloom** (`[data-theme="midnight-bloom"]`):
  - Vibe: Orchid petals glowing in darkness, restrained for comfort
  - Background hue ~300 (violet), accent hue ~330 (magenta-orchid)
  - Background: deep violet-black (low lightness ~12%, low chroma ~0.02)
  - Accent: magenta-orchid (lightness ~68%, chroma ~0.18)
  - Surfaces shift from cool violet to warm purple undertones

  **Copper Forge** (`[data-theme="copper-forge"]`):
  - Vibe: Warm industrial — polished copper pipes, workshop lighting
  - Background hue ~50-60 (warm brown), accent hue ~55-70 (copper/orange)
  - Background: warm charcoal-brown (lightness ~12%, chroma ~0.015)
  - Accent: burnished copper (lightness ~70%, chroma ~0.14)

  **Ocean Depth** (`[data-theme="ocean-depth"]`):
  - Vibe: Deep sea bioluminescent — very dark with glowing teal
  - Background hue ~240-250 (navy), accent hue ~185-195 (aquamarine/teal)
  - Background: abyssal navy-black (lightness ~11%, chroma ~0.02)
  - Accent: aquamarine/teal (lightness ~72%, chroma ~0.12)

  **Nebula Dust** (`[data-theme="nebula-dust"]`):
  - Vibe: Hubble nebula photos — pink-coral wisps against space
  - Background hue ~290-300 (space purple), accent hue ~15-25 (pink-coral)
  - Background: deep space purple-black (lightness ~12%, chroma ~0.02)
  - Accent: stellar pink-coral (lightness ~70%, chroma ~0.16)

  **Obsidian** (`[data-theme="obsidian"]`):
  - Vibe: Pure monochrome editorial — zero saturation, sharp contrast
  - All colors: chroma = 0 (true neutral grays)
  - Background: near-black (lightness ~10%)
  - Accent: silver (lightness ~65%)
  - High contrast for focused writing, crisp editorial feel

  **Jade Temple** (`[data-theme="jade-temple"]`):
  - Vibe: Natural jade, zen, serene, organic
  - Background hue ~155-165 (forest green), accent hue ~155-165 (jade/emerald)
  - Background: very dark forest green (lightness ~12%, chroma ~0.015)
  - Accent: muted emerald-jade (lightness ~65%, chroma ~0.10)

  For each theme, the --glass-glow value follows the pattern: `0 0 0 2px <accent-oklch-with-0.2-alpha>`.

  Status colors (success/error/warning/info) can reuse the common values from existing themes unless they clash with the theme palette. Keep success green, error red, warning amber, info blue — just adjust if the theme's accent or background causes contrast issues.
  </action>
