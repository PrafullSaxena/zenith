```ts
export interface GroomingResult {
  priority: 'p1' | 'p2' | 'p3'
  priorityRationale: string          // one sentence, e.g. "P1 — blocks auth release this week"
  suggestedAction: 'do' | 'delegate' | 'defer' | 'delete'
  evidenceSummary: string | null     // bullet list, one bullet per source with results
  jiraTicketKey: string | null       // only when AI is confident it's the same work item
  jiraTicketUrl: string | null
  researchSummary: string | null     // 3-5 sentence synthesis — only for research-mode tasks
  researchLinks: string | null       // JSON: {title: string, url: string}[] — up to 5 links
  groomedAt: number                  // Date.now()
}
```

**Exported function:**

```ts
export async function groomTask(task: import('../taskgroomer/database').Task): Promise<GroomingResult>
```

**Implementation:**

1. **Gather API key for Claude:** Call `await getApiKeyForProvider('claude')` from `src/main/ai/providers.ts`. If undefined, throw `new Error('Anthropic API key not configured. Set it in Settings > Code Review Bot > Provider.')`.

2. **Gather integration credentials:** Read from `src/main/integrations/credentials.ts` using `getIntegrationCredential(CRED_JIRA_BASE_URL)`, `getIntegrationCredential(CRED_JIRA_EMAIL)`, `getIntegrationCredential(CRED_JIRA_API_TOKEN)`, `getIntegrationSetting(CRED_JIRA_PROJECTS)`, `getIntegrationCredential(CRED_CONFLUENCE_BASE_URL)`, `getIntegrationCredential(CRED_CONFLUENCE_EMAIL)`, `getIntegrationCredential(CRED_CONFLUENCE_API_TOKEN)`. Build `JiraCredentials | null` and `ConfluenceCredentials | null` (null if any required field is missing).

3. **Query integrations in parallel with 30s timeout each:** Wrap each integration call in a `withTimeout(promise, 30000)` helper that races against a `setTimeout` reject. On timeout or error, return the skip sentinel for Jira/Confluence (`{results:[], skipped:true, reason:'error'}`) or the web skip sentinel (`{results:[], skipped:true, reason:'error', strategy:null}`) — never throw.

   ```ts
   const [jiraResult, confluenceResult, webResult] = await Promise.all([
     withTimeout(searchJira(task.text, jiraCredentials), 30000),
     withTimeout(searchConfluence(task.text, confluenceCredentials), 30000),
     withTimeout(webSearch(task.text), 30000),
   ])
   ```

   `withTimeout<T>(promise: Promise<T>, ms: number): Promise<T>` — returns a version of `promise` that rejects with `new Error('timeout')` after `ms` ms. The caller wraps each integration call with its own try/catch to return the appropriate skip sentinel (not let the timeout error propagate).

4. **Build integration context string** for the AI prompt:
   - If `jiraResult.skipped === false` and `jiraResult.results.length > 0`: append Jira issues as `"JIRA: {key} — {summary} [{status}]"` per issue (max 5).
   - If `confluenceResult.skipped === false` and `confluenceResult.results.length > 0`: append pages as `"CONFLUENCE: {title} — {excerpt}"` per result (max 3).
   - `webSearch()` returns a `SearchResponse` object `{results: SearchResult[], skipped: boolean, reason: 'error' | null, strategy: ...}` — NOT a plain array. Check `webResult.skipped === false && webResult.results.length > 0`, then iterate `webResult.results` (each has `title`, `url`, `snippet`): append as `"WEB: {title} — {url}"` per result (max 5).
   - If all sources returned nothing, set integrationContext to `"No integration results found."`.

5. **Build the AI prompt:**

   System prompt:
   ```
   You are a task grooming assistant for a software developer. You analyze tasks and produce structured grooming output. You MUST respond with valid JSON only — no markdown, no explanation, just the JSON object.
   ```

   User prompt:
   ```
   Groom this task:

   TASK: {task.text}

   INTEGRATION CONTEXT:
   {integrationContext}

   Respond with exactly this JSON structure (no other text):
   {
     "priority": "p1" | "p2" | "p3",
     "priorityRationale": "<one sentence explaining why, e.g. P1 — blocks the auth release>",
     "suggestedAction": "do" | "delegate" | "defer" | "delete",
     "evidenceSummary": "<bullet list with one bullet per source that returned results, e.g. '• Jira: PROJ-42 in progress — auth token bug\\n• Web: 3 relevant articles found'. null if no sources returned results.>",
     "jiraTicketKey": "<Jira key like PROJ-42 only when you are confident this is the SAME work item, or null>",
     "jiraTicketUrl": "<full URL if jiraTicketKey is set, or null>",
     "isResearchMode": true | false,
     "researchSummary": "<3-5 sentence synthesis of all findings — only include if isResearchMode is true, otherwise null>",
     "researchLinks": [{"title": "...", "url": "..."}] | null
   }

   Research mode rules:
   - Set isResearchMode=true if the task is ambiguous, technical, multi-part, or unclear what to do next.
   - Set isResearchMode=false if the task is short and clear (e.g. "Fix typo in docs", "Update package version").
   - researchLinks: up to 5 links from Jira, Confluence, or web results. null if isResearchMode=false.

   Priority rules:
   - P1: Do today — blocks something, urgent, time-sensitive
   - P2: Do this week — important but not today
   - P3: Someday — low urgency, nice to have

   4D rules:
   - Do: You should act on this yourself
   - Delegate: Someone else should handle this
   - Defer: Do it later, not urgent
   - Delete: This is no longer relevant or worthwhile
   ```

6. **Call Claude via Vercel AI SDK `generateText`** (non-streaming — batch result is sufficient per decision):

   ```ts
   import { generateText } from 'ai'

   const model = createModel('claude', 'claude-sonnet-4-6', apiKey)
   const { text } = await generateText({
     model,
     system: systemPrompt,
     prompt: userPrompt,
     maxTokens: 1024,
   })
   ```

7. **Parse the JSON response.** Wrap in try/catch. If parsing fails, throw with a descriptive message including the raw text (truncated to 200 chars). Map parsed fields to `GroomingResult`. Set `groomedAt: Date.now()`. Validate required fields (priority, suggestedAction) are present and valid enum values — throw if not.

8. **Set researchLinks** from `parsed.researchLinks`: if `parsed.isResearchMode === true` and `parsed.researchLinks` is a non-empty array, serialize to JSON string for the DB column. Otherwise null.

The function must be fully typed with no `any` — use type assertions sparingly and only when necessary.
