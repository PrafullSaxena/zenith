    Define each utility with these exact values (from RESEARCH.md recommendations):

    1. `@utility text-hero` — 2.5rem (40px), weight 800, line-height 1.1, letter-spacing -0.025em
    2. `@utility text-h1` — 1.875rem (30px), weight 700, line-height 1.2, letter-spacing -0.02em
    3. `@utility text-h2` — 1.5rem (24px), weight 600, line-height 1.25, letter-spacing -0.015em
    4. `@utility text-h3` — 1.25rem (20px), weight 600, line-height 1.3, letter-spacing -0.01em
    5. `@utility text-body` — 0.875rem (14px), weight 400, line-height 1.6, letter-spacing 0
    6. `@utility text-small` — 0.8125rem (13px), weight 400, line-height 1.5, letter-spacing 0.01em
    7. `@utility text-caption` — 0.75rem (12px), weight 500, line-height 1.4, letter-spacing 0.02em
    8. `@utility text-mono` — 0.8125rem (13px), weight 400, line-height 1.6, letter-spacing 0.02em, PLUS `font-family: var(--font-mono);`

    Each @utility block format:
    ```css
    @utility text-hero {
      font-size: 2.5rem;
      font-weight: 800;
      line-height: 1.1;
      letter-spacing: -0.025em;
    }
    ```

    **Important notes:**
    - text-mono is the ONLY utility that sets font-family. All others inherit from the parent (which uses --font-sans by default on body).
    - These are Tailwind v4 @utility directives, NOT @layer utilities or plain CSS classes. The @utility directive makes them available as Tailwind utility classes with proper specificity and tree-shaking.
    - Do NOT conflict with existing Tailwind text-* utilities (text-sm, text-lg, etc.). The names text-hero, text-h1, etc. are custom and won't conflict because Tailwind's built-in scale uses text-xs/sm/base/lg/xl/2xl/etc.

    **Verify no Tailwind conflicts:** Ensure none of these names (text-hero, text-h1, text-h2, text-h3, text-body, text-small, text-caption, text-mono) collide with existing Tailwind v4 utilities. "text-body" and "text-small" are not built-in Tailwind classes. "text-mono" — check if Tailwind v4 has a built-in `text-mono` utility. If it does (unlikely — `font-mono` is the Tailwind utility for monospace), proceed with `text-mono` as our custom utility since it combines font-family with size/weight/spacing.
