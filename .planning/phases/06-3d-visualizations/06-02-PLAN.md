**Create KnowledgeGraph3D.tsx** — port MindGraph3D architecture from Cortex, adapted for Nebula's note data:

1. **Data preparation:**
   - Props: `{ graphData: { nodes: GraphNode[], links: GraphLink[] }, onNodeClick: (nodeId: string) => void }`
   - Import GraphNode type from `../../types/nebula`
   - Map nodes to SimNode with id, label (note title), color (by tag/category — use a palette of 8 distinct colors cycling through tags), position xyz
   - Links come directly from graphData.links

2. **d3-force-3d simulation (same pattern as MindGraph3D):**
   - `forceSimulation(nodes).force('charge', forceManyBody().strength(-60)).force('link', forceLink(links).id(d => d.id).distance(25)).force('center', forceCenter()).alpha(1).alphaDecay(0.015)`
   - Use refs for position updates in useFrame (NOT state — improve on MindGraph3D's setPositions pattern)
   - Stop simulation in cleanup

3. **3D scene (InnerScene):**
   - Lighting: ambientLight 0.3, pointLight [100, 100, 100] 0.8
   - Nodes: sphereGeometry with radius based on connection count (1.2 + connections * 0.15, min 1.5)
   - Material: meshStandardMaterial with node color, emissive glow on hover (0.8 vs 0.3)
   - Edges: `<Line>` from drei with `color="#475569" lineWidth={0.5} opacity={0.3} transparent`
   - Hover tooltip: `<Html center distanceFactor={80}>` with glass styling showing note title and tag
   - Click: call `onNodeClick(node.id)` to navigate to note
   - OrbitControls: autoRotate={!reducedMotion} autoRotateSpeed={0.3}, enablePan, enableZoom, enableRotate

4. **Auto-rotate pause on hover:** Same pattern as Activity Mesh — controlsRef, pauseAutoRotate callback, 3s idle resume.

5. **Reduced motion:** usePrefersReducedMotion controls autoRotate.

6. **Exported component:** Default export wraps Canvas with camera={{ position: [60, 40, 60], fov: 55 }}, transparent bg, touchAction: 'none'.
