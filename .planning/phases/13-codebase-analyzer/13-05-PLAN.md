3. Set `store.setIsQAStreaming(true)`
4. Build the system prompt with codebase context:
   ```typescript
   const analysisResult = store.analysisResult
   const systemPrompt = `You are a codebase expert analyzing a ${analysisResult.repoType} repository.
   Repository type: ${analysisResult.repoType}, Framework: ${analysisResult.framework}, Language: ${analysisResult.language}

   ## Code Structure Summary
   - ${analysisResult.stats.totalFiles} files, ${analysisResult.stats.totalLines} lines
   - Entities: ${JSON.stringify(analysisResult.stats.entityCount)}
   - API Routes: ${analysisResult.routes.length}

   ## Key Entities (top 50)
   ${analysisResult.entities.slice(0, 50).map(e => `- ${e.kind}: ${e.name} (${e.filePath}:${e.line})`).join('\n')}

   ## API Endpoints
   ${analysisResult.routes.map(r => `- ${r.method} ${r.fullPath} → ${r.handlerName} (${r.filePath}:${r.line})`).join('\n')}

   Answer questions accurately. Reference specific files, functions, and line numbers. Format responses in markdown.`
   ```
5. Use the existing AI streaming infrastructure:
   ```typescript
   // Get the user's configured AI provider from settings
   const settings = await window.api.settings.getAll()
   const providerId = settings['ai.provider'] as string
   const modelName = settings['ai.model'] as string
   const sessionId = crypto.randomUUID()

   // Set up stream listeners
   window.api.ai.onStreamChunk(({ sessionId: sid, chunk }) => {
     if (sid === sessionId) {
       store.updateLastQAMessage(prev => prev + chunk)  // append chunk
     }
   })
   window.api.ai.onStreamDone(({ sessionId: sid }) => {
     if (sid === sessionId) {
       store.setIsQAStreaming(false)
       window.api.ai.removeStreamListeners()
       // Parse source citations from the response
     }
   })
   window.api.ai.onStreamError(({ sessionId: sid, error }) => {
     if (sid === sessionId) {
       store.updateLastQAMessage(`Error: ${error}`)
       store.setIsQAStreaming(false)
       window.api.ai.removeStreamListeners()
     }
   })

   // Start the analysis stream
   await window.api.ai.startAnalysis(providerId, modelName, systemPrompt, question, sessionId)
   ```

NOTE on `updateLastQAMessage`: The store action currently takes a string (replacement), not an appender. For streaming, the implementation needs to accumulate chunks. Two approaches:
- Option A: Use a ref to accumulate chunks outside the store, update store on each chunk: `accumulatorRef.current += chunk; store.updateLastQAMessage(accumulatorRef.current)`
- Option B: Modify the store action to accept a function: `updateLastQAMessage(fn: (prev: string) => string)`. Choose Option A (simpler, no store modification needed).

Clear chat button: Trash2 icon in the header area, calls `store.clearQA()`.
