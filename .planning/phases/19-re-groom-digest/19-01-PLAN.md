Implementation details:

```typescript
ipcMain.handle('taskgroomer:regroom', async (_event, args: { taskId: string }) => {
  if (groomingRunActive) {
    return { started: false, reason: 'already_running' }
  }
  groomingRunActive = true

  const db = getTaskGroomerDb()
  const tasks = db.listTasks()
  const task = tasks.find((t) => t.id === args.taskId)

  if (!task) {
    groomingRunActive = false
    return { started: false, reason: 'task_not_found' }
  }

  try {
    const result = await groomTask(task)

    // Merge strategy: preserve existing Jira link if AI returns null for those fields
    const existingJiraKey = task.jiraTicketKey
    const existingJiraUrl = task.jiraTicketUrl

    db.updateTask({
      id: task.id,
      fields: {
        priority: result.priority,
        priorityRationale: result.priorityRationale,
        suggestedAction: result.suggestedAction,
        evidenceSummary: result.evidenceSummary,
        jiraTicketKey: result.jiraTicketKey ?? existingJiraKey,
        jiraTicketUrl: result.jiraTicketUrl ?? existingJiraUrl,
        researchSummary: result.researchSummary,
        researchLinks: result.researchLinks,
        groomedAt: result.groomedAt
      }
    })

    return {
      started: true,
      result: {
        priority: result.priority,
        priorityRationale: result.priorityRationale,
        suggestedAction: result.suggestedAction,
        evidenceSummary: result.evidenceSummary,
        jiraTicketKey: result.jiraTicketKey ?? existingJiraKey,
        jiraTicketUrl: result.jiraTicketUrl ?? existingJiraUrl,
        researchSummary: result.researchSummary,
        researchLinks: result.researchLinks,
        groomedAt: result.groomedAt
      }
    }
  } catch (err) {
    const message = err instanceof Error ? err.message : 'Unknown error'
    return { started: true, result: null, error: message }
  } finally {
    groomingRunActive = false
  }
})
```

Key points:
- Uses the shared `groomingRunActive` module-level flag — same lock as `taskgroomer:groom`. One groom at a time, no queuing.
- Does NOT change task status — task stays in its current status per user decision.
- Jira merge strategy: `result.jiraTicketKey ?? existingJiraKey` — only overwrites if AI returns a non-null value. This implements "preserve Jira link unless AI returns new high-confidence one".
- `listTasks()` returns all tasks regardless of status (re-groom works on any status per user decision).
- Returns the merged result in response so the renderer can update in-place without another IPC fetch.
- The handler is synchronous from the renderer's perspective (awaits the result). Unlike `taskgroomer:groom` which is fire-and-forget, re-groom returns the full result synchronously.
