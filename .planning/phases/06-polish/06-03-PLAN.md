  <action>
1. **Global reduced-motion CSS** in `src/renderer/src/index.css`:
   Add at the end of the file:
   ```css
   @media (prefers-reduced-motion: reduce) {
     *, *::before, *::after {
       animation-duration: 0.01ms !important;
       animation-iteration-count: 1 !important;
       transition-duration: 0.01ms !important;
       scroll-behavior: auto !important;
     }
   }
   ```
   This is the nuclear option that ensures ALL CSS animations and transitions are disabled globally when the user prefers reduced motion. Framer Motion already respects this via its own `useReducedMotion`, but this catches plain CSS transitions on all components.

2. **Global focus-visible ring** in `src/renderer/src/index.css`:
   Add a global focus-visible style that applies to any interactive element not already styled:
   ```css
   :focus-visible {
     outline: 2px solid hsl(var(--ring));
     outline-offset: 2px;
   }
   ```
   This provides a baseline visible focus ring. Components with their own `focus-visible:ring-*` classes (like Button) will override this via specificity.

3. **Sidebar ARIA** in `sidebar.tsx`:
   - Add `role="navigation"` and `aria-label="Main navigation"` to the `<motion.aside>` element
   - Add `aria-label="Plugin navigation"` to the Reorder.Group container
   - The toggle button already has `aria-label` -- verify it's correct
   - Add `aria-current="page"` to active NavLink items (NavLink with `isActive` should get this)

4. **Input ARIA** in `input.tsx`:
   - Verify the Input component forwards `aria-label`, `aria-describedby`, `aria-invalid` props correctly (it should via `...props` spread -- just confirm)
   - Ensure focus ring styles are present: add `focus-visible:ring-2 focus-visible:ring-ring/50 focus-visible:border-ring` if not already in the base classes

5. **Select ARIA** in `select.tsx`:
   - Same check as input -- ensure focus-visible ring styles exist on the trigger element

1. Create `src/renderer/src/lib/bundle-audit.sh`:
   A shell script that:
   - Runs `npx electron-vite build` (or the project's build command -- check package.json scripts)
   - Measures the total size of the renderer output directory (typically `out/renderer/`)
   - Lists the top 10 largest JS chunks by file size
   - Outputs a summary table

   Script contents:
   ```bash
   #!/bin/bash
   # Bundle Size Audit for Zenith UI Revamp
   # Run from project root: bash src/renderer/src/lib/bundle-audit.sh

   echo "=== Zenith Bundle Size Audit ==="
   echo ""

   # Build
   echo "Building..."
   npx pnpm run build 2>&1 | tail -5

   echo ""
   echo "=== Renderer Bundle Size ==="

   # Find renderer output
   RENDERER_DIR=$(find out -name "renderer" -type d 2>/dev/null | head -1)
   if [ -z "$RENDERER_DIR" ]; then
     RENDERER_DIR="out"
   fi

   # Total size
   echo "Total: $(du -sh "$RENDERER_DIR" 2>/dev/null | cut -f1)"
   echo ""

   # Top JS chunks
   echo "=== Top 10 JS Chunks ==="
   find "$RENDERER_DIR" -name "*.js" -exec ls -lh {} \; 2>/dev/null | awk '{print $5, $NF}' | sort -rh | head -10

   echo ""
   echo "=== Three.js Check ==="
   # Verify no three.js in bundle
   grep -rl "THREE" "$RENDERER_DIR"/*.js 2>/dev/null && echo "WARNING: THREE references found!" || echo "PASS: No THREE.js references in bundle"
   grep -rl "@react-three" "$RENDERER_DIR"/*.js 2>/dev/null && echo "WARNING: @react-three references found!" || echo "PASS: No @react-three references in bundle"

   echo ""
   echo "=== Expected Savings ==="
   echo "Three.js (~600KB), @react-three/fiber (~200KB), @react-three/drei (~300KB), d3-force-3d (~50KB)"
   echo "Expected total savings: ~1.1MB+ of JavaScript removed"
   ```

2. Run the audit and capture results:
   - Execute the script: `bash src/renderer/src/lib/bundle-audit.sh`
   - If the build fails (common in Electron projects with missing native deps in CI), instead do a simpler check:
     - Run `npx pnpm ls three @react-three/fiber @react-three/drei d3-force-3d 2>&1` to confirm packages are not installed
     - Run `grep -r "from 'three'" src/ --include="*.ts" --include="*.tsx" | wc -l` to confirm zero imports
     - Run `grep -r "@react-three" src/ --include="*.ts" --include="*.tsx" | wc -l` to confirm zero imports
     - Document findings in the script output comments
  </action>
