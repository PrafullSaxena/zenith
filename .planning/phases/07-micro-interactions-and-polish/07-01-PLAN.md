**AnimatedIcon.tsx** — Create a shared component that wraps icon swaps with AnimatePresence for smooth transitions:
- Props: `icon: LucideIcon`, `iconKey: string` (unique key that changes when icon changes — drives AnimatePresence), `size?: number` (default 14), `className?: string`
- Wrap icon in `AnimatePresence mode="wait" initial={false}` with a `motion.span` keyed by `iconKey`
- Animation: `initial={{ opacity: 0, scale: 0.8 }}`, `animate={{ opacity: 1, scale: 1 }}`, `exit={{ opacity: 0, scale: 0.8 }}`
- Transition: `{ type: 'spring', stiffness: 500, damping: 30, duration: 0.15 }`
- Add `display: inline-flex` to the motion.span so it doesn't break inline layouts
- Import `usePrefersReducedMotion` from `@renderer/lib/useReducedMotion` — when reduced motion active, use `{ duration: 0.01 }` transition (instant swap, no spring)

**ScrollContainer.tsx** — Create a reusable wrapper providing scroll progress bar and scroll shadows:
- Props: `children: ReactNode`, `className?: string`, `showProgress?: boolean` (default true), `showShadows?: boolean` (default true)
- Use THREE refs (no React state for scroll position): `containerRef`, `progressRef`, `topShadowRef`, `bottomShadowRef`
- `onScroll` handler reads `scrollTop`, `scrollHeight`, `clientHeight` from containerRef
- Progress bar: a 2px tall div, accent-colored (`bg-[var(--color-accent)]`), positioned absolute at top of container. Width set via `progressRef.current.style.width = \`${percentage}%\``
- Top shadow: 20px tall gradient from `var(--color-bg-base)` to transparent, positioned absolute at top below progress bar. Opacity toggled via ref when `scrollTop > 0`
- Bottom shadow: 20px tall gradient from transparent to `var(--color-bg-base)`, positioned absolute at bottom. Opacity toggled via ref when `scrollTop < scrollHeight - clientHeight - 1`
- Container div: `overflow-y: auto`, `position: relative`, passes through `className`
- Initial check: use `useEffect` with ResizeObserver on containerRef to set initial shadow visibility on mount and when content size changes
- Transition on shadow opacity: `transition-opacity duration-150` CSS class for smooth fade

**index.ts** — Add exports for both new components:
- `export { AnimatedIcon } from './AnimatedIcon'`
- `export { ScrollContainer } from './ScrollContainer'`
