**1. Create `src/renderer/src/types/textcraft.ts`:**

Define these types:

```typescript
export type ToneOption = 'professional' | 'casual' | 'technical' | 'friendly' | 'concise'
export type FormatOption = 'email' | 'one-pager' | 'technical-doc' | 'general'

export interface RefinementOptions {
  tone: ToneOption
  format: FormatOption
  customInstructions: string  // per-request freeform instructions (e.g., "make it shorter")
}

export interface RefinementSession {
  sessionId: string
  status: 'idle' | 'streaming' | 'complete' | 'error'
  rawText: string       // accumulated AI output (markdown)
  inputText: string     // original user input (for reference)
  options: RefinementOptions  // options used for this refinement
}

export interface TextCraftHistoryEntry {
  id: string            // unique ID (e.g., `textcraft-${Date.now()}`)
  inputText: string
  outputText: string
  options: RefinementOptions
  createdAt: string     // ISO date string
}
```

**2. Create `src/renderer/src/stores/textcraft-store.ts`:**

Follow the launchpad-store.ts AI streaming pattern exactly. The store should have:

**State:**
- `inputText: string` (default '')
- `options: RefinementOptions` (default: tone='professional', format='email', customInstructions='')
- `session: RefinementSession | null` (default null)
- `history: TextCraftHistoryEntry[]` (default [])
- `error: string | null` (default null)

**Actions:**
- `setInputText(text: string)` -- updates inputText
- `setOptions(partial: Partial<RefinementOptions>)` -- merges into options
- `startRefinement(agentId: string, model: string, command: string)` -- builds system prompt from current options, creates sessionId `textcraft-${Date.now()}`, sets up session-scoped IPC listeners (onStreamChunk, onStreamDone, onStreamError), calls `window.api.ai.startAnalysis(agentId, model, systemPrompt, inputText, sessionId, command)`. MUST check sessionId in each callback. MUST call `window.api.ai.removeStreamListeners()` in done AND error callbacks. On done, also auto-save to history via `saveToHistory`.
- `cancelRefinement()` -- if session.status === 'streaming', calls `window.api.ai.cancelAnalysis(sessionId)`, sets status to 'idle', calls `removeStreamListeners()`.
- `saveToHistory(entry: TextCraftHistoryEntry)` -- prepends to history, caps at MAX_HISTORY_ENTRIES (50), persists via `window.api.settings.set(HISTORY_STORAGE_KEY, updated)`.
- `loadHistory()` -- reads from `window.api.settings.get(HISTORY_STORAGE_KEY)`, validates as array, sets state. Wrap in try/catch with fallback to empty array.
- `loadFromHistory(entry: TextCraftHistoryEntry)` -- sets inputText, options, and creates a completed session with the outputText.
- `clearSession()` -- resets session to null, error to null.

**System Prompt Builder (module-level function `buildSystemPrompt`):**

Use the exact system prompt from the RESEARCH.md code example. Include tone descriptions map, format instructions map, and the structured prompt template with RULES section. The function takes `RefinementOptions` and returns a string.

**Constants:**
- `HISTORY_STORAGE_KEY = 'textcraft.history'`
- `MAX_HISTORY_ENTRIES = 50`

**Token tracking:** After onStreamDone, capture token usage via `useTokenStore.getState().addEntry(...)` following the launchpad-store pattern (estimate from rawText.length / 4 if no usage data).

Import `create` from 'zustand', types from '../types/textcraft', and `useTokenStore` from './token-store'.
