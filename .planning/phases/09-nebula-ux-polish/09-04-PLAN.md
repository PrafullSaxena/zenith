1. **Rewrite VoiceRecorder.tsx as FAB pattern**:
   - Import `motion, AnimatePresence` from `framer-motion`.
   - The component renders in a positioned container: `absolute bottom-6 right-6 z-40`.
   - **Idle state**: A round FAB button (48x48px, `rounded-full bg-accent shadow-lg hover:bg-accent/90 transition-colors`) with a Mic icon (lucide). On click, calls `startRecording()`.
   - **Recording state**: FAB expands into a small card using framer-motion `AnimatePresence mode="wait"`:
     - `<motion.button>` for idle state with `initial={{ scale: 0 }} animate={{ scale: 1 }} exit={{ scale: 0 }}`.
     - `<motion.div>` for recording card with `initial={{ width: 48, height: 48, borderRadius: 24 }} animate={{ width: 280, height: 80, borderRadius: 16 }}`.
     - Card contents: 4 animated equalizer bars (using the CSS keyframes from main.css — `equalizer-bar` class, each bar is a 3px-wide rounded div with `bg-accent`), elapsed timer (MM:SS format), and a red stop button (Square icon).
   - **Processing state**: Card shows a spinner (Loader2 icon spinning) with "Transcribing..." text.
   - **Audio storage**: After recording stops, before sending for transcription, also call `window.api.nebula.saveAudio(noteId, audioBuffer)` to persist the audio file for playback. This is in addition to the existing transcription IPC call.
   - Keep the existing MediaRecorder logic (getUserMedia, isTypeSupported check, ondataavailable, onstop) from the current VoiceRecorder but restructure it within the FAB pattern.
   - **Background processing** per user decision: After stopping recording, immediately set state to 'processing' and allow the user to continue editing. The transcription IPC call runs asynchronously. When it completes, trigger the `handleTranscription` pipeline and fire a toast notification.
   - Remove the old bottom-bar recorder layout entirely.

2. **Create TranscriptionBlock.tsx**:
   - An inline component rendered inside the note content area, below the Tiptap editor.
   - Props: `noteId: string`, `transcription: TranscriptionSegment[]` (array of `{ speaker: string; text: string }` segments), `audioPath?: string`.
   - **Collapsible**: starts expanded, click a header toggle to collapse. Use framer-motion `motion.div` with `animate={{ height: 'auto' }}` / `animate={{ height: 0 }}` or simple max-height transition.
   - **Header**: "Transcription" label with ChevronDown/ChevronRight icon toggle and a small play button (Play icon from lucide) if audioPath is set.
   - **Colored speaker labels**: Assign a unique accent color to each speaker. Use a deterministic color map based on speaker name hash: cycle through 6 preset oklch colors (cyan, pink, green, amber, purple, blue). Each speaker label rendered as a small colored pill (`text-xs px-2 py-0.5 rounded-full font-medium`).
   - **Editable speaker names**: Click on a speaker label to edit it. Show a small inline text input replacing the label. On blur or Enter, rename the speaker in ALL segments of this transcription (not just the clicked one). Update the note's transcription data in the store.
   - **Segment rendering**: Each segment shows: colored speaker pill, then text content. Segments separated by small margin.
   - **Audio playback**: The play button loads audio via `window.api.nebula.loadAudio(noteId)`, converts the number[] back to a Uint8Array, creates an audio Blob (type `audio/webm`), and plays via `new Audio(URL.createObjectURL(blob))`. Show Play/Pause toggle during playback. Dispose the URL on component unmount.

3. **Create ToastContainer.tsx**:
   - Reads `toasts` from useNebulaStore.
   - Renders at `fixed bottom-6 left-1/2 -translate-x-1/2 z-50` (or `fixed bottom-20 right-6 z-50` to avoid overlapping with the FAB).
   - Use framer-motion `AnimatePresence` to animate toasts in/out:
     - Enter: `initial={{ opacity: 0, y: 20, scale: 0.95 }} animate={{ opacity: 1, y: 0, scale: 1 }}`
     - Exit: `exit={{ opacity: 0, y: -10, scale: 0.95 }}`
   - Each toast: `rounded-lg border border-border bg-surface-elevated px-4 py-3 shadow-xl cursor-pointer text-sm text-text-primary`.
   - If toast has a `noteId`, clicking it navigates to that note (call `selectNote(noteId)` from store).
   - Toasts auto-dismiss after 5 seconds (handled by the store's addToast setTimeout).
  </action>
