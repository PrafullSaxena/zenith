         - `onClick={onClose}` — clicking backdrop closes modal.
       - **Modal content**: `motion.div` with:
         - Outer wrapper: `fixed inset-0 z-50 flex items-center justify-center p-4` (centers the dialog)
         - Inner dialog: `bg-[var(--glass-bg)] backdrop-blur-[var(--glass-blur)] border border-[var(--glass-border)] rounded-2xl shadow-2xl shadow-black/40` — BLUR tier.
         - Import `modalContent` variant from `@renderer/lib/motion` for scale animation (or define inline: initial `{ opacity: 0, scale: 0.95 }`, animate `{ opacity: 1, scale: 1 }`, exit `{ opacity: 0, scale: 0.97 }`, transition enter `{ duration: 0.2, ease: [0.4, 0, 0.2, 1] }`, transition exit `{ duration: 0.12 }`).

         - `onClick={e => e.stopPropagation()}` on the inner dialog to prevent backdrop click from firing when clicking content.
       - **Escape key**: Add `useEffect` that listens for `keydown` event on `document`. If `e.key === 'Escape'` and `isOpen`, call `onClose`. Clean up on unmount or when `isOpen` changes.
       - **Focus trap**: Implement `useFocusTrap` hook (per RESEARCH.md pattern):

         - Query all focusable elements inside the modal ref: `button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])`.
         - Focus the first focusable element.
         - On `keydown` Tab: if at last focusable, wrap to first. If Shift+Tab at first, wrap to last.
         - On unmount (when isOpen becomes false), restore focus to previousFocus.
       - **Accessibility**: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` pointing to title element ID (if title provided).
       - **Body scroll lock**: When isOpen, add `overflow: hidden` to `document.body`. Remove on close/unmount. Use `useEffect` for cleanup.

    **IMPORTANT:** Modal is BLUR tier (uses backdrop-blur). Only 1 modal at a time (per CONTEXT.md — no nested modal support needed).     1. **Create `stores/toast-store.ts`**:
       - Zustand store following existing project pattern (see other stores in `src/renderer/src/stores/` for conventions).
       - Toast interface:
         ```typescript
         interface Toast {
           id: string
           type: 'success' | 'error' | 'warning' | 'info'
           message: string
           duration: number  // default 5000ms
         }
         ```
       - Store state: `toasts: Toast[]`
       - Store actions:
         - `addToast(toast: Omit<Toast, 'id' | 'duration'> & { duration?: number })`: Generate unique ID (`Date.now().toString(36) + Math.random().toString(36).slice(2)`), default duration 5000ms, prepend to array (newest first), if length > 3 remove oldest.
         - `removeToast(id: string)`: Filter out toast by ID.
         - `clearToasts()`: Empty the array.
       - Export `useToastStore` hook.

    2. **Create `GlassToast.tsx`** (COMP-09):
       - This is a **container component** that reads from the toast store and renders all active toasts.
       - Position: `fixed bottom-4 right-4 z-[60] flex flex-col-reverse gap-2` — bottom-right, stacks upward (newest at bottom due to `flex-col-reverse`).
       - Max 3 visible (enforced by the store).
       - Each toast item is a `motion.div` with blur-tier glass styling: `bg-[var(--glass-bg)] backdrop-blur-[var(--glass-blur)] border border-[var(--glass-border)] rounded-xl p-4 shadow-lg shadow-black/30 min-w-[320px] max-w-[420px]`.
       - Animation: `AnimatePresence` wraps the toast list. Each toast enters from right: initial `{ opacity: 0, x: 100 }`, animate `{ opacity: 1, x: 0 }`, exit `{ opacity: 0, x: 100, transition: { duration: 0.15 } }`. Enter transition: `{ type: 'spring', stiffness: 400, damping: 30 }`.
       - Toast layout:
         - Left: Type icon from lucide-react — `CheckCircle2` (success), `XCircle` (error), `AlertTriangle` (warning), `Info` (info). Color matches type semantic color token.
         - Center: Message text `text-sm text-[var(--text-primary)]`.
         - Right: Close button (X icon) — calls `removeToast(id)`.
       - **Progress bar**: Thin bar at bottom of toast (`h-0.5 rounded-full`). Color matches toast type color. Starts at full width, shrinks to 0 over `duration` ms using CSS animation or inline style: `width: ${remainingPercent}%` updated via `requestAnimationFrame` or CSS `@keyframes` with `animation-duration` set to toast duration.
         - Simpler approach: Use a `<motion.div>` that animates from `width: '100%'` to `width: '0%'` over `duration` seconds. `initial={{ width: '100%' }}`, `animate={{ width: '0%' }}`, `transition={{ duration: toast.duration / 1000, ease: 'linear' }}`.
       - **Auto-dismiss with pause-on-hover**: Implement the `useAutoTimer` pattern from RESEARCH.md:
         - Each toast gets its own timer via a sub-component (e.g., `ToastItem`).
         - Track `remaining` time in state. On mount, start setTimeout for `remaining` ms → calls `removeToast`.
         - `onMouseEnter`: Clear timeout, save `remaining - elapsed`.
         - `onMouseLeave`: Restart timeout with saved remaining time.
         - When paused, the progress bar animation should also pause: use `animationPlayState: paused` CSS or framer-motion `animate` controls.
       - **Type color map**:
         - `success`: `text-[var(--color-success)]`, progress `bg-[var(--color-success)]`
         - `error`: `text-[var(--color-error)]`, progress `bg-[var(--color-error)]`
         - `warning`: `text-[var(--color-warning)]`, progress `bg-[var(--color-warning)]`
         - `info`: `text-[var(--color-info)]`, progress `bg-[var(--color-info)]`
