    1. **Create `GlassCard.tsx`** (COMP-01):
       - Props interface: `variant` (default | interactive | selected, default 'default'), `children`, `className`, `onClick`

       - **Blur tier** — uses `GLASS_BASE.blur` (has backdrop-blur). This is the key difference from GlassSurface.
       - Base classes: `rounded-2xl p-4 transition-all duration-[var(--duration-fast)]`
       - Variant behavior:
         - `default`: Static card, renders as plain `<div>`. No animation.
         - `interactive`: Renders as `motion.div`. Import `hoverLift` from `@renderer/lib/motion` and spread it. Add `cursor-pointer` and hover border brightening: `hover:border-white/[0.12] hover:shadow-lg hover:shadow-black/20`. The hoverLift provides `whileHover: { y: -2 }` and `whileTap: { scale: 0.97 }`.
         - `selected`: Renders as plain `<div>`. Add `border-l-[3px] border-l-[var(--color-accent)]/30` for the left accent bar. Slightly different background: `bg-[var(--color-accent)]/[0.04]` layered on top.
       - Conditional rendering: Use `motion.div` only when `variant === 'interactive'`, otherwise use plain `div`. This avoids unnecessary motion overhead.

    2. **Create `GlassSelect.tsx`** (COMP-05):
       - Props interface: `options` (Array<{ value: string; label: string }>), `value` (string), `onChange` ((value: string) => void), `placeholder` (string, optional), `disabled` (boolean), `error` (boolean), `className`
       - Internal state: `isOpen` (boolean), `highlightedIndex` (number)
       - Translucent tier (no backdrop-blur on trigger or dropdown).
       - Trigger button: Styled like GlassInput — `bg-[var(--glass-bg)] border border-[var(--glass-border)] rounded-xl px-3 py-2 text-sm`. Shows selected label or placeholder. Chevron icon from lucide-react (`ChevronDown`) rotates on open.
       - Dropdown: `position: absolute` (inline, not portal — per research recommendation). Styled with `bg-[var(--glass-bg)] border border-[var(--glass-border)] rounded-xl mt-1 py-1 shadow-xl shadow-black/30 z-50`. Use `AnimatePresence` + `motion.div` with opacity 0->1 and y: -4->0 for enter, reverse for exit.
       - Option items: `px-3 py-2 text-sm cursor-pointer hover:bg-white/[0.06]`. Selected option shows `text-[var(--color-accent)] bg-[var(--color-accent)]/10`. Highlighted (keyboard) option shows `bg-white/[0.06]`.
       - Keyboard navigation: `ArrowDown`/`ArrowUp` moves highlight, `Enter`/`Space` selects, `Escape` closes. When opening, highlight the currently selected option.
       - Click outside closes: Use a `useEffect` with `mousedown` event listener on `document`. Clean up on unmount.
       - Focus ring on trigger: `focus-visible:outline-none focus-visible:shadow-[var(--glass-glow)]`
       - Disabled state: `opacity-40 cursor-not-allowed pointer-events-none`
       - Error state: `border-[var(--color-error)]/60` on trigger.

    3. **Create `GlassTab.tsx`** (COMP-06):
       - Props interface: `tabs` (Array<{ id: string; label: string; icon?: LucideIcon }>), `activeTab` (string), `onTabChange` ((id: string) => void), `className`
       - Translucent tier (no backdrop-blur).
       - Container: `flex gap-1 p-1 rounded-xl bg-[var(--glass-bg)] border border-[var(--glass-border)]`
       - Tab buttons: `relative px-4 py-2 text-sm font-medium rounded-lg transition-colors duration-[var(--duration-fast)]`. Inactive: `text-[var(--text-secondary)] hover:text-[var(--text-primary)] hover:bg-white/[0.04]`. Active: `text-[var(--color-accent)]`.
       - Sliding underline: Use `motion.div` with `layoutId="activeTab"` for the active indicator. Render it as a child of the active tab button — `absolute bottom-0 left-0 right-0 h-0.5 bg-[var(--color-accent)] rounded-full`. The `layoutId` makes it smoothly slide between tabs using Framer Motion's layout animation.
       - If `icon` is provided, render it before the label: `<Icon size={16} className="mr-1.5" />`
       - Add `role="tablist"` on container, `role="tab"` and `aria-selected` on each button.

    **IMPORTANT:** GlassCard is BLUR tier (it's a top-level surface). GlassSelect and GlassTab are TRANSLUCENT tier. GlassSelect dropdown uses inline absolute positioning (not portal). GlassTab underline uses layoutId for smooth sliding.

       - **Parallax effect**: Use `useState` for `{ x: number, y: number }` offset (default 0,0). Add `onMouseMove` handler on the outer container:
         ```typescript
         const handleMouseMove = (e: React.MouseEvent) => {
           const rect = e.currentTarget.getBoundingClientRect()
           const x = ((e.clientX - rect.left) / rect.width - 0.5) * 8  // +/-4px
           const y = ((e.clientY - rect.top) / rect.height - 0.5) * 8
           setOffset({ x, y })
         }
         const handleMouseLeave = () => setOffset({ x: 0, y: 0 })
         ```
         Apply to the icon wrapper: `<motion.div animate={{ x: offset.x, y: offset.y }} transition={{ type: 'spring', stiffness: 150, damping: 15 }}>`.
