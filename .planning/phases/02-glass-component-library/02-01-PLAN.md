    1. **Create `GlassButton.tsx`** (COMP-03):
       - Props interface: `variant` (default | primary | danger | ghost, default 'default'), `size` (sm | md | lg, default 'md'), `disabled`, `children`, `className`, `onClick`, `type` (button | submit | reset, default 'button'), plus `React.ButtonHTMLAttributes<HTMLButtonElement>` spread.
       - Use `forwardRef<HTMLButtonElement>`.
       - Render as `motion.button` (from framer-motion) for whileTap animation.
       - Variant map (translucent tier, no backdrop-blur):
         - `default`: `bg-[var(--glass-bg)] border-[var(--glass-border)] text-[var(--text-primary)] hover:bg-white/[0.06]`
         - `primary`: `bg-[var(--color-accent)]/20 border-[var(--color-accent)]/30 text-[var(--color-accent)] hover:bg-[var(--color-accent)]/30`
         - `danger`: `bg-[var(--color-error)]/20 border-[var(--color-error)]/30 text-[var(--color-error)] hover:bg-[var(--color-error)]/30`
         - `ghost`: `bg-transparent border-transparent text-[var(--text-secondary)] hover:bg-white/[0.04]`
       - Size map:
         - `sm`: `px-2.5 py-1 text-xs rounded-lg`
         - `md`: `px-4 py-2 text-sm rounded-xl`
         - `lg`: `px-6 py-2.5 text-base rounded-xl`
       - Base classes: `inline-flex items-center justify-center gap-2 border font-medium transition-colors duration-[var(--duration-fast)]`
       - Animation: `whileTap={{ scale: 0.97 }}` — import from motion if available or define inline. Apply `transition={{ duration: 0.1 }}` for the tap. Do NOT apply whileTap when disabled.
       - Focus ring: `focus-visible:outline-none focus-visible:shadow-[var(--glass-glow)]` (accent glow ring per CONTEXT.md).
       - Disabled state: `disabled:opacity-40 disabled:cursor-not-allowed disabled:pointer-events-none` — pointer-events-none suppresses all hover/focus.

    2. **Create `GlassInput.tsx`** (COMP-04):
       - Props interface: `error` (boolean, default false), `errorMessage` (string, optional), `label` (string, optional), `className`, plus `React.InputHTMLAttributes<HTMLInputElement>` spread.
       - Use `forwardRef<HTMLInputElement>`.
       - Render as plain `<input>` (no motion needed).
       - Base classes (translucent tier): `bg-[var(--glass-bg)] border border-[var(--glass-border)] rounded-xl px-3 py-2 text-sm text-[var(--text-primary)] placeholder:text-[var(--text-secondary)]/50 w-full transition-colors duration-[var(--duration-fast)]`
       - Focus state: `focus:outline-none focus:shadow-[var(--glass-glow)]` (accent glow ring).
       - Error state: When `error` is true, replace border with `border-[var(--color-error)]/60` and focus glow with `focus:shadow-[0_0_0_2px_var(--color-error)/40]`.
       - Disabled state: `disabled:opacity-40 disabled:cursor-not-allowed`
       - If `label` provided, wrap input in a `<div>` with a `<label>` above using `text-sm text-[var(--text-secondary)] mb-1.5` classes.
       - If `errorMessage` provided and `error` is true, render a `<p>` below input with `text-xs text-[var(--color-error)] mt-1`.
       - No backdrop-blur.

    **IMPORTANT:** GlassButton must import `motion` from `framer-motion`. Both components use `forwardRef` for composability. Both are translucent tier. Focus ring uses `--glass-glow` token (box-shadow: 0 0 0 2px var(--glass-glow) per CONTEXT.md decision).
