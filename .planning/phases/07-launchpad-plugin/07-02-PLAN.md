    Create `src/renderer/src/stores/launchpad-store.ts` following the db-store.ts pattern:
    - Import `create` from zustand
    - Import types from `../types/launchpad` (CloudProvider, ServiceSelection, ResourceConfig, EstimationEntry, AiAdvisorSession, AiSuggestion, LaunchpadTab, EstimationExport)
    - Import `calculateTotalCost` from `../data/cloud-pricing/calculator`
    - Import `getCatalog` from `../data/cloud-pricing/index`
    - Import `useTokenStore` from `./token-store` (for AI token tracking)

    Constants:
    - `HISTORY_STORAGE_KEY = 'launchpad.estimationHistory'`
    - `MAX_HISTORY_ENTRIES = 50`

    Interface `LaunchpadStore`:
    - State: provider (CloudProvider | null), selectedServices (ServiceSelection[]), activeTab (LaunchpadTab), history (EstimationEntry[]), aiSession (AiAdvisorSession | null), pendingSuggestions (AiSuggestion | null), comparisonProviders (CloudProvider[])
    - Computed-like getters exposed as functions: getCurrentCatalog(), getTotalCost()
    - Actions:
      - setProvider(provider: CloudProvider): set provider, clear selectedServices
      - setActiveTab(tab: LaunchpadTab): set activeTab
      - addService(categoryId: string, serviceId: string): add to selectedServices with default config from catalog
      - removeService(serviceId: string): remove from selectedServices
      - updateServiceConfig(serviceId: string, config: ResourceConfig): update config for a specific service
      - saveEstimation(name: string): Promise<void> — build EstimationEntry from current state (provider, services, calculated totals), prepend to history, cap at MAX_HISTORY_ENTRIES, persist via `window.api.settings.set(HISTORY_STORAGE_KEY, ...)`
      - loadHistory(): Promise<void> — load from `window.api.settings.get(HISTORY_STORAGE_KEY)`, set history
      - loadEstimation(entry: EstimationEntry): restore provider + services from a history entry
      - deleteHistoryEntry(id: string): remove from history, persist
      - clearEstimation(): reset provider, selectedServices, pendingSuggestions
      - startAiChat(question: string, agentId: string, model: string, command?: string): set up aiSession, call window.api.ai.startAnalysis with LAUNCHPAD_AI_SYSTEM_PROMPT + question, wire up stream listeners (onStreamChunk, onStreamDone, onStreamError) following db-store pattern — on done, parse suggestions from rawText
      - cancelAiChat(): call window.api.ai.cancelAnalysis, cleanup listeners
      - applySuggestions(): if pendingSuggestions exists, set provider and populate selectedServices from suggestion, clear pendingSuggestions
      - dismissSuggestions(): clear pendingSuggestions
      - setComparisonProviders(providers: CloudProvider[]): set which providers to compare
      - exportPdf(): Promise<string | null> — build EstimationExport from current state, call window.api.launchpad.exportPdf, return filePath

    Define LAUNCHPAD_AI_SYSTEM_PROMPT constant inside the file (as in research). Include instructions for the AI to return structured JSON suggestions in a ```suggestions code fence.

    Helper `parseSuggestions(rawText: string): AiSuggestion | null`:
    - Use regex to find content between ```suggestions and ``` fences
    - Try JSON.parse inside try/catch
    - Return null on any failure (lenient parsing per research anti-pattern guidance)
