    Create `src/renderer/src/data/cloud-pricing/calculator.ts`:
    - Import types from launchpad.ts and catalogs
    - Export `HOURS_PER_MONTH = 730` constant
    - Export `calculateServiceCost(serviceId: string, config: ResourceConfig, catalog: ProviderCatalog): ServiceCostResult`
      - Look up service in catalog by serviceId
      - Switch on service type/id to apply correct pricing formula:
        - EC2/Compute Engine/Azure VM: pricePerHour * usageHoursPerMonth * quantity
        - S3/Cloud Storage/Blob Storage: storageGb * pricePerGb + transferOutGb * transferPrice
        - Lambda/Cloud Functions/Azure Functions: (requests * requestPrice) + (gbSeconds * durationPrice)
        - RDS/Cloud SQL/Azure SQL: pricePerHour * HOURS_PER_MONTH * quantity (or flat monthly for Azure SQL)
        - DynamoDB/Firestore/Cosmos DB: readUnits * readPrice + writeUnits * writePrice
        - EBS/Persistent Disk/Managed Disk: sizeGb * pricePerGb (monthly)
        - CloudFront/Cloud CDN/Azure CDN: gb * pricePerGb
        - Data Transfer: gb * pricePerGb
        - API Gateway/App Service/Cloud Run: compute based on requests or instances
      - Return { monthly, yearly: monthly * 12, breakdown: CostLineItem[] }
      - Handle unknown serviceId gracefully (return zero cost with empty breakdown)
    - Export `calculateTotalCost(selections: ServiceSelection[], catalog: ProviderCatalog): { totalMonthly: number; totalYearly: number; items: Array<{ serviceId: string; serviceName: string } & ServiceCostResult> }`
      - Iterate selections, call calculateServiceCost for each, sum totals
    - Wrap all calculation in try/catch — never throw, return zero cost on invalid input
