1. **Create ResultsGrid.tsx:**
   - Props: `{ rows: Record<string, unknown>[], fields: { name: string, dataTypeID: number }[], hasMore: boolean, isLoading: boolean, error?: string, errorLine?: number }`
   - Use `@tanstack/react-virtual` `useVirtualizer` for row virtualization:
     - Parent container ref, estimateSize = 32px per row, overscan = 15
     - Container is `overflow-auto` filling available height
   - **Column headers:**
     - Each header cell is a button — click to toggle sort (asc -> desc -> none cycle)
     - Sort state: `sortColumn: string | null`, `sortDirection: 'asc' | 'desc' | null` in local useState
     - Sort rows in `useMemo` — use stable sort. For NULLs, push to end regardless of sort direction (matching PostgreSQL default NULLS LAST). Handle numeric vs string comparison based on `typeof value`.
     - Each header has a right-edge drag handle for column resizing. Use mousedown/mousemove/mouseup pattern. Store column widths in local state `columnWidths: Record<string, number>`, default width = `max(100, headerTextWidth * 8)`.
   - **Cell rendering:**
     - NULL values: render `<span className="italic text-text-secondary/50 text-xs">NULL</span>` badge
     - Boolean values: render as `true`/`false` text with subtle color coding
     - Long strings (>50 chars) or JSON objects: truncate display to 50 chars with "..." suffix. On hover, show a tooltip with first 200 chars. On click, open CellModal with full value.
     - Numbers: right-align in cell
     - Regular values: render as `String(value)`
   - **Click to copy cell:** clicking a cell copies its value to clipboard via `navigator.clipboard.writeText(String(value))`. Show brief visual feedback (cell background flash).
   - **Right-click context menu on row:** show native-style context menu (positioned div) with "Copy Row as JSON" and "Copy Row as TSV" options. Use JSON.stringify for JSON, tab-separated values for TSV.
   - **Toolbar above the grid:**
     - "Copy All as TSV" button — copies all loaded rows as tab-separated values (headers + rows)
     - "Export CSV" button — calls `window.api.app.saveTextFile(csvContent, 'query-results.csv', [{ name: 'CSV', extensions: ['csv'] }])`
     - "Export JSON" button — calls `window.api.app.saveTextFile(jsonContent, 'query-results.json', [{ name: 'JSON', extensions: ['json'] }])`
     - Row count label: "Showing {rows.length} rows" (or "Showing {rows.length} of {rows.length}+ rows" if `hasMore`)
   - **CSV serialization** (inline, no library needed): headers row + data rows, escape commas/quotes/newlines per RFC 4180. Wrap fields containing special chars in double quotes, escape internal quotes by doubling them.
   - **JSON serialization:** `JSON.stringify(rows, null, 2)`
   - **Error display:** if `error` prop is set, show error message in the results area with red text and a warning icon. Don't show the grid.
   - **Loading state:** if `isLoading`, show a centered spinner
   - **Empty state:** if rows is empty and no error, show "No results" message

2. **Create CellModal.tsx:**
   - Props: `{ value: unknown, fieldName: string, isOpen: boolean, onClose: () => void }`
   - Modal overlay (fixed inset-0, bg-black/60, z-50)
   - Modal content panel (centered, max-w-2xl, max-h-[80vh], overflow-auto, bg-surface, rounded-lg, border border-border)
   - Header: field name + close button (X)
   - Body: if value is object/array, render as syntax-highlighted JSON (use `<pre>` with monospace font). If string, render as plain text with word-wrap. If null, show NULL badge.
   - Copy button at bottom to copy full value
   - Close on Escape key and click outside
