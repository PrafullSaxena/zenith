**Azure Retail Prices API:**
`https://prices.azure.com/api/retail/prices?$filter=serviceName eq 'Virtual Machines'`

No auth required. Paginated via `nextPageLink` field in response.

**Function signature:**
```typescript
export interface AzureFetchResult {
  servicesUpdated: number
  deltaSkipped: boolean
  bytesDownloaded: number
  error?: string
}

export async function fetchAzurePricing(): Promise<AzureFetchResult>
```

**12 Azure regions to sync:**
```typescript
const AZURE_REGIONS = [
  'eastus', 'eastus2', 'westus', 'westus2',
  'westeurope', 'northeurope', 'southeastasia', 'eastasia',
  'japaneast', 'brazilsouth', 'canadacentral', 'australiaeast'
]
```

**Delta strategy:**
Use a sidecar file at `app.getPath('userData')/pricing-azure-meta.json` storing `{ lastSyncAt: string }` (ISO date string).

On first sync: no `$filter` date constraint — fetch all.
On subsequent syncs: append `and lastModified ge datetime'<ISO-date>'` to the filter query param where `<ISO-date>` is the stored `lastSyncAt` value.

Example filtered URL:
```
https://prices.azure.com/api/retail/prices?$filter=serviceName eq 'Virtual Machines' and lastModified ge datetime'2026-03-30T00:00:00Z' and armRegionName in ('eastus','westus',...)
```

Also filter by region using `armRegionName in (...)` to limit response size. Build the filter string dynamically:
```typescript
const regionList = AZURE_REGIONS.map(r => `'${r}'`).join(',')
const baseFilter = `serviceName eq 'Virtual Machines' and armRegionName in (${regionList})`
const dateFilter = lastSyncAt ? ` and lastModified ge datetime'${lastSyncAt}'` : ''
const filter = baseFilter + dateFilter
```

**Pagination:**
Azure API returns up to 100 items per page with a `nextPageLink` field. Follow `nextPageLink` until it is null/undefined. Accumulate all items.

**Parsing:**
Each item in `Items` array has:
- `armRegionName` — matches our region list
- `retailPrice` — USD on-demand price per hour
- `unitOfMeasure` — typically "1 Hour"
- `skuName` — e.g. "D2 v3"

Map to `RateRow`:
```typescript
{
  service_id: 'azure-vm',  // canonical service ID — check seed.ts for exact string
  provider: 'azure',
  region: item.armRegionName,
  rate_key: 'pricePerHour',
  value: item.retailPrice,
  unit: 'USD/hr',
  tier: 'onDemand',
  fetched_at: Date.now()
}
```

Call `pricingRepository.upsertRates(rows)` in batches of 500.

**If delta returns zero items:** That is valid — means nothing changed. Return `{ servicesUpdated: 0, deltaSkipped: false, bytesDownloaded: 0 }`.

After successful upsert: write `{ lastSyncAt: new Date().toISOString() }` to the sidecar.

**Error handling:** Wrap in try/catch. On error return `{ servicesUpdated: 0, deltaSkipped: false, bytesDownloaded: 0, error: error.message }`. Do NOT throw.

**HTTP client:** Use Node's built-in `https` module with a helper that returns the full body as a string (reuse the same pattern as aws-fetcher if plan 08-01 has already established it, otherwise implement the same `httpsGet(url): Promise<string>` helper locally).

const GCP_REGIONS = [

**API pagination:**
GCP returns paginated results via `nextPageToken`. Follow pages until `nextPageToken` is absent.

**Endpoint:**
```
GET https://cloudbilling.googleapis.com/v1/services/6F81-5844-456A/skus?key={apiKey}&pageToken={token}
```

**Parsing:**
Each SKU has:
- `serviceRegions` — array of region strings (e.g. `["us-central1", "us-east1"]`)
- `pricingInfo[0].pricingExpression.tieredRates[0].unitPrice` — `{ units: string, nanos: number }`
- `description` — human-readable SKU name

Convert price: `value = parseInt(units) + nanos / 1_000_000_000`

Only process SKUs where `serviceRegions` intersects with `GCP_REGIONS` and SKU description contains "Instance Core" or "Instance Ram" (to limit scope to compute rates).

Map to `RateRow` for each intersecting region:
```typescript
{
  service_id: 'gcp-compute-engine',  // check seed.ts for exact string

  region: gcpRegion,
  rate_key: description.includes('Core') ? 'pricePerCoreHour' : 'pricePerGbHour',
  value: computedPrice,
  unit: 'USD/hr',
  tier: 'onDemand',
  fetched_at: Date.now()
}
```

**Delta strategy (SYNC-06):**
GCP uses ETag per request. Store ETags in `app.getPath('userData')/pricing-gcp-meta.json` as `{ etag: string }`. On each request, send `If-None-Match: <etag>` header. If response is `304 Not Modified`, count as delta skip for that page and skip upsert. Update stored ETag from response `ETag` header after successful fetch.
