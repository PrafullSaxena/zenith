    **ipc-handlers.ts** -- Register two new IPC handlers:

    1. `launchpad:getCredentialStatus` -- Returns an object with credential presence and masked values for all 4 credential keys:
       ```ts
       {
         gcpApiKey: { set: boolean, masked: string | null },
         awsAccessKeyId: { set: boolean, masked: string | null },
         awsSecretAccessKey: { set: boolean, masked: string | null },
         gcpBillingAccountId: { set: boolean, masked: string | null }
       }
       ```
       Uses `hasCredential()` for `set` and `getCredentialMasked()` for `masked`.

    2. `launchpad:deleteCredential` -- Accepts `{ key: 'gcpApiKey' | 'awsAccessKeyId' | 'awsSecretAccessKey' | 'gcpBillingAccountId' }`. Maps the friendly key to the CRED_* constant and calls `deleteCredential()`. Returns `{ deleted: boolean }`.

    **preload/index.ts** -- Add `getCredentialStatus()` and `deleteCredential(key)` to the launchpad section, following the same `ipcRenderer.invoke()` pattern as existing entries.

    **electron.d.ts** AND **preload/index.d.ts** -- Add type declarations for both new methods on the launchpad API surface. The `getCredentialStatus` return type matches the shape above. The `deleteCredential` accepts `{ key: string }` and returns `Promise<{ deleted: boolean }>`.

    - Four credential rows, each with: label, masked value display ("••••" + last 4 chars from getCredentialStatus), Edit button, Clear button.
    - Fields: "AWS Access Key ID", "AWS Secret Access Key", "GCP API Key", "GCP Billing Account ID".
    - Edit flow (per user decision): click Edit -> field expands inline to a text input with Save/Cancel buttons. On Save: call `window.api.launchpad.saveCredentials({ [key]: value })`, then refresh credential status. On Cancel: collapse back.
    - Clear flow (per user decision): click Clear -> show AlertDialog (use existing AlertDialog component) with message "Are you sure? This will disable live pricing for [provider]." On confirm: call `window.api.launchpad.deleteCredential({ key })`, refresh status.

    **Section 3: Provider Status**
    - Three mini cards (one per provider: AWS, GCP, Azure) displayed in a flex row.
    - Each card shows: provider name, colored status dot + label (green = "Live", gray = "No Key", amber = "Stale"), last-sync timestamp as relative time ("2 hours ago", "Yesterday", "Never").
    - Use a tooltip (existing Tooltip component) on the timestamp to show exact date/time.
    - Status logic: fetch `window.api.launchpad.getSyncStatus()` on mount. For each provider:

      - If lastSyncAt is null -> "No Key" if no key, else show "Never synced"
      - If lastSyncAt exists and is within 2x sync frequency -> "Live" (green dot)
      - If lastSyncAt exists but older than 2x sync frequency -> "Stale" (amber dot)
    - Colored dots: use the SAME `h-2 w-2 rounded-full` pattern from AgentRow (bg-green-500, bg-gray-500, bg-amber-500).
