**SplitPanel (`split-panel.tsx`):**

Props interface:
```ts
interface SplitPanelProps {
  direction?: 'horizontal' | 'vertical'  // default 'horizontal'
  sizes?: number[]  // default panel sizes in percentages
  minSizes?: number[]  // minimum sizes in percentages
  children: React.ReactNode[]  // Each child becomes a panel
  className?: string
  onResize?: (sizes: number[]) => void
}
```

Implementation:
1. Import `PanelGroup`, `Panel`, `PanelResizeHandle` from `react-resizable-panels`
2. Wrap children in `PanelGroup` with `direction` prop
3. For each child, render inside a `Panel` with `defaultSize` from `sizes` array and `minSize` from `minSizes`
4. Between each panel, render `PanelResizeHandle` styled as:
   - Horizontal: `w-1.5 bg-transparent hover:bg-primary/20 active:bg-primary/40 transition-colors cursor-col-resize` with a centered 24px vertical grip line (`w-0.5 h-6 rounded-full bg-border`)
   - Vertical: `h-1.5 bg-transparent hover:bg-primary/20 active:bg-primary/40 transition-colors cursor-row-resize` with a centered 24px horizontal grip line (`h-0.5 w-6 rounded-full bg-border`)
5. Pass `onResize` through to `PanelGroup`'s `onLayout` callback

Export: Named export `SplitPanel`

**SearchInput (`search-input.tsx`):**

Props interface:
```ts
interface SearchInputProps {
  placeholder?: string  // default "Search..."
  onSearch: (query: string) => void
  debounceMs?: number  // default 300
  icon?: LucideIcon  // default Search from lucide
  shortcut?: string  // e.g. "Cmd+K" — displayed as hint badge
  className?: string
  autoFocus?: boolean
}
```

Implementation:
1. Use shadcn `Input` component as base
2. Wrap in a `div` with `relative` positioning
3. Left side: Icon rendered at `absolute left-3 top-1/2 -translate-y-1/2 size-4 text-muted-foreground`
4. Input: `pl-10` to make room for icon, `pr-16` if shortcut hint present
5. Right side: If `shortcut` provided, render a `kbd` element: `absolute right-3 top-1/2 -translate-y-1/2 text-xs text-muted-foreground bg-secondary px-1.5 py-0.5 rounded border border-border font-mono`
6. Debounce: Use `useRef` for timeout + `useCallback` pattern. On each `onChange`, clear existing timeout, set new one with `debounceMs` delay. Call `onSearch` with trimmed value. Also call immediately on empty string (clear search instantly).
7. Controlled internal state with `useState` for the input value

Export: Named export `SearchInput`
