1. **Collapse state**: Add `isCollapsed` state (default: true to match current 56px behavior). Store collapse preference in `useSettingsStore` via `getSetting('general.sidebarCollapsed')` / `setSetting('general.sidebarCollapsed', boolean)`.

2. **Cmd+B keyboard shortcut**: Add `useEffect` with `keydown` listener for `metaKey + 'b'` (Mac) / `ctrlKey + 'b'` (Windows) that toggles `isCollapsed`. Call `e.preventDefault()` to prevent browser default.

3. **Animated width**: Use `framer-motion` `motion.aside` with `animate={{ width: isCollapsed ? 56 : 240 }}` and `transition={{ type: 'spring', damping: 20, stiffness: 300 }}`. Keep `flex-shrink-0`.

4. **Styling per design spec**:
   - Background: `bg-card/88 backdrop-blur-[14px]` (card at 88% opacity + blur)
   - Border: `border-r border-border`
   - Active item: `bg-primary/18 border border-primary/35` with primary text
   - Hover: `bg-secondary` with foreground text
   - Replace old Glass classes (`bg-surface`, `text-text-secondary`, `var(--glass-bg)`, `var(--color-accent-glow)`) with shadcn tokens

5. **Expanded mode labels**: When `!isCollapsed`, show text labels next to icons using `motion.span` with `animate={{ opacity: isCollapsed ? 0 : 1 }}` and `overflow-hidden`. Labels should fade in/out smoothly.

6. **Toggle button**: Add a hamburger/panel-left icon button at top (below drag region) that toggles `isCollapsed`. Use `PanelLeft` from lucide-react.

7. **Logo**: Show "Z" badge in primary color at top. When expanded, show "Zenith" text next to it.

8. **Preserve ALL existing functionality**:
   - `SidebarIcon` component with `NavLink` routing
   - `layoutId="sidebarActiveBar"` sliding indicator
   - `Reorder.Group` / `Reorder.Item` for plugin drag reorder
   - `buildOrderedPlugins` helper
   - `ICON_MAP` with all lucide icons
   - `GripVertical` drag handles (visible in expanded mode, hidden when collapsed)
   - Fixed app icons (Dashboard, Activity) at top, Settings/About at bottom

9. **Tooltip behavior**: Keep tooltips on hover for collapsed mode. Hide tooltips when expanded (labels are visible). Use shadcn `Tooltip` component instead of custom CSS tooltip.

10. **Export**: Named export `Sidebar` and also export `useSidebarCollapsed` hook that returns `[isCollapsed, toggleCollapsed]` for CommandPalette and other consumers.
