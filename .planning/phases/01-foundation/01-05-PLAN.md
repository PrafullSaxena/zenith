**Agent types** (`src/renderer/src/types/agent.ts`):
```ts
export type AgentStatus = 'connected' | 'failed' | 'not-configured' | 'testing'

export type AgentProviderType = 'cloud' | 'local' | 'custom'

export interface AgentProvider {
  id: string                    // Unique identifier (e.g., 'claude', 'ollama', 'custom-xyz')
  name: string                  // Display name (e.g., 'Claude', 'Ollama')
  type: AgentProviderType       // cloud, local, or custom
  baseUrl: string               // API base URL (empty for cloud providers that use official SDK)
  model: string                 // Model identifier (e.g., 'claude-sonnet-4-20250514', 'llama3')
  status: AgentStatus           // Current connection status
  isCustom: boolean             // true for user-added providers
  requiresApiKey: boolean       // Whether this provider needs an API key
  hasApiKey: boolean            // Whether API key has been set (from credentials store)
}
```

Define the 6 pre-listed providers as a constant array `DEFAULT_PROVIDERS`:
1. **Claude:** id='claude', name='Claude', type='cloud', baseUrl='', model='claude-sonnet-4-20250514', requiresApiKey=true
2. **Gemini:** id='gemini', name='Gemini', type='cloud', baseUrl='', model='gemini-2.0-flash', requiresApiKey=true
3. **Codex:** id='codex', name='Codex', type='cloud', baseUrl='', model='codex', requiresApiKey=true
4. **Opencode:** id='opencode', name='Opencode', type='cloud', baseUrl='', model='', requiresApiKey=true
5. **Ollama:** id='ollama', name='Ollama', type='local', baseUrl='http://localhost:11434', model='', requiresApiKey=false
6. **Cursor-agent:** id='cursor-agent', name='Cursor Agent', type='local', baseUrl='', model='', requiresApiKey=false

All start with status='not-configured', isCustom=false, hasApiKey=false.

**Agent store** (`src/renderer/src/stores/agent-store.ts`):
Zustand store:
```ts
interface AgentStoreState {
  providers: AgentProvider[]
  isLoading: boolean
  loadProviders: () => Promise<void>
  testConnection: (providerId: string) => Promise<void>
  setApiKey: (providerId: string, apiKey: string) => Promise<void>
  addCustomProvider: (provider: Omit<AgentProvider, 'status' | 'isCustom' | 'hasApiKey'>) => Promise<void>
  removeCustomProvider: (providerId: string) => Promise<void>
  getConfiguredProviders: () => AgentProvider[]
}
```

- `loadProviders`: Read saved agents from `window.api.settings.get('agents')`. Merge with DEFAULT_PROVIDERS (defaults are always present, saved state overrides status/model/baseUrl). For each provider that requiresApiKey, check `window.api.credentials.has(providerId)` to set hasApiKey. For Ollama, auto-probe via `window.api.app.probeOllama()` — if available, set status='connected' and populate model with first available model.
- `testConnection`: Set provider status to 'testing', then:
  - For Ollama: call `window.api.app.probeOllama()` — if available, status='connected', else 'failed'
  - For cloud providers: check hasApiKey. If no API key, status='not-configured'. If has key, status='connected' (actual API validation will come in Phase 3 when we have real API clients — for now, having a key means "configured").
  - For custom providers: same as cloud — key presence = configured.
  - Update status in store state and persist to `window.api.settings.set('agents.{id}.status', status)`
- `setApiKey`: Call `window.api.credentials.set(providerId, apiKey)`, update hasApiKey=true in state, persist.
- `addCustomProvider`: Generate id as `custom-${Date.now()}`, set isCustom=true, status='not-configured', hasApiKey=false. Add to providers array. Persist to settings.
- `removeCustomProvider`: Only allows removing providers where isCustom=true. Remove from array and settings.
- `getConfiguredProviders`: Returns providers where status is 'connected' or hasApiKey is true.

Persist the providers list (minus sensitive data) to `agents.providers` via window.api.settings.
