  <action>
Add AI summarization logic to `nebula-store.ts`. Follow the same AI streaming pattern used in launchpad-store.ts and review-store.ts.

1. Define the summarization system prompt as a module-level constant:
   ```
   const SUMMARIZE_SYSTEM_PROMPT = `You are a knowledge assistant. Given a note's content, produce a JSON object with:
   1. "title": A concise title (max 10 words) capturing the note's main idea
   2. "summary": A 2-3 sentence summary of the key points
   3. "topics": An array of 3-7 key topics/concepts mentioned (single words or short phrases)
   4. "connections": An array of general topic keywords that could connect this note to others

   Output ONLY valid JSON, no markdown fences, no explanation:
   {"title":"...","summary":"...","topics":["..."],"connections":["..."]}`
   ```

2. Add a `triggerSummarization(note: NoteFile)` action to the store:
   - Get the configured AI agent for nebula plugin: read from `useAgentStore` or `useSettingsStore` to get the provider/model. Use the same agent fallback pattern as CodeReviewBot (first provider with connected/hasApiKey status if no default agent set).
   - Generate a sessionId: `nebula-summarize-${note.id}-${Date.now()}`
   - Set up session-scoped IPC listeners (same pattern as launchpad AI):
     - `window.api.ai.onStreamChunk`: accumulate chunks into a local string
     - `window.api.ai.onStreamDone`: Parse accumulated JSON, extract { title, summary, topics, connections }. Update the note with new summary/topics. Call `window.api.nebula.saveNote(updatedNote)`. Then infer edges: for each connection keyword, find other notes whose topics array includes that keyword (using the notes list from the store or a new IPC call). Call `window.api.nebula.updateEdges(note.id, matchedEdges)`. Finally call `loadGraphData()` to refresh the graph. Clean up listeners.
     - `window.api.ai.onStreamError`: Log error, clean up listeners.
   - Call `window.api.ai.startAnalysis(providerId, modelName, SUMMARIZE_SYSTEM_PROMPT, noteContentAsText, sessionId)`.
   - Set `isSummarizing: true, summarizeSessionId: sessionId`.

3. Add an `inferEdges(noteId: string, topics: string[], connections: string[])` helper:
   - Iterate over the `notes` array in the store state.
   - For each other note that has overlapping topics (compare topics arrays), create an edge.
   - Call `window.api.nebula.updateEdges(noteId, edges)` where edges = `[{ targetId, relationship: 'shares-topic', weight: overlapCount }]`.
   - This is a simple keyword-overlap approach. The AI provides the `connections` field for broader matching.

4. Modify the existing `saveNote` action: After successfully saving, check if the note has meaningful content (more than 20 characters of plain text). If so, call `triggerSummarization(note)` fire-and-forget (don't await).

5. Add cleanup: in a `cleanup()` action, call `window.api.ai.removeStreamListeners()` to prevent listener accumulation (same session-scoped pattern as CodeReviewBot).

IMPORTANT: The summarization is fire-and-forget. The note saves immediately. AI summarization runs in background and updates the note asynchronously. Do NOT block the save on summarization completing.
