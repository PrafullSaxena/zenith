1. Create `src/main/nebula/transcription.ts`:
   - Import `OpenAI` from `openai`, `fs` from `node:fs`.
   - Define interfaces locally (no renderer imports):
     ```
     interface TranscriptionSegment {
       speaker: string
       text: string
       start: number
       end: number
     }
     interface DiarizedTranscript {
       text: string
       segments: TranscriptionSegment[]
     }
     ```
   - Export async function `transcribeAudio(audioPath: string, apiKey: string): Promise<DiarizedTranscript>`:
     - Create OpenAI client: `new OpenAI({ apiKey })`.
     - Call `client.audio.transcriptions.create()` with:
       - `model: 'gpt-4o-transcribe'` (use the standard transcription model; if diarize variant is available, use `'gpt-4o-transcribe-diarize'` -- try-catch fallback to `'gpt-4o-transcribe'` if the diarize model 404s)
       - `file: fs.createReadStream(audioPath)`
       - `response_format: 'verbose_json'`
     - Map response segments to DiarizedTranscript format:
       ```
       {
         text: response.text,
         segments: (response.segments || []).map(seg => ({
           speaker: (seg as any).speaker ?? 'Speaker 1',
           text: seg.text,
           start: seg.start,
           end: seg.end,
         }))
       }
       ```
     - Handle errors: If no API key, throw `'OpenAI API key not configured. Set it in Settings > AI Agents.'`. If transcription fails, throw with error message.

2. Update `src/main/ipc-handlers.ts`:
   - Import `transcribeAudio` from `./nebula/transcription`.
   - Replace the stub `nebula:transcribeAudio` handler with the real implementation:
     ```
     ipcMain.handle('nebula:transcribeAudio', async (_event, audioBuffer: number[]) => {
       const tmpPath = path.join(app.getPath('temp'), `nebula-${Date.now()}.webm`)
       try {
         fs.writeFileSync(tmpPath, Buffer.from(audioBuffer))
         // Get OpenAI API key from credentials store
         const encrypted = credentialsStore.get('openai-api-key') as string | undefined
         if (!encrypted) {
           // Try getting from settings as fallback
           const settingsKey = getSetting('agents.openai.apiKey') as string
           if (!settingsKey) throw new Error('OpenAI API key not configured')
           const result = await transcribeAudio(tmpPath, settingsKey)
           return result
         }
         const apiKey = safeStorage.decryptString(Buffer.from(encrypted, 'base64'))
         const result = await transcribeAudio(tmpPath, apiKey)
         return result
       } finally {
         // Cleanup temp file
         try { fs.unlinkSync(tmpPath) } catch { /* ignore */ }
       }
     })
     ```
     NOTE: The API key retrieval should follow the existing agent store pattern. Look at how other plugins get API keys. The credential key for OpenAI is typically stored via the agent configuration. Check the existing `getApiKeyForProvider` pattern in `ai/stream.ts` and reuse it. If there's a helper function, import and use it. If not, read from the credentials store using the openai provider key pattern.

   - Also add `nebula:saveTranscription` handler:
     ```
     ipcMain.handle('nebula:saveTranscription', async (_event, record) => {
       const { db } = getNebulaInstances()
       db.saveTranscription(record)
       return { saved: true }
     })
     ```
   - Add corresponding entry in preload and index.d.ts for `saveTranscription`.
