  <action>
1. Create `src/renderer/src/stores/nebula-store.ts` — Zustand store for Nebula:
   Import types from `../types/nebula` (NoteListItem, NoteFile, NebulaTab, GraphData, SearchResult, VoiceRecordingState, DiarizedTranscript).

   State shape:
   ```
   {
     // Tab navigation
     activeTab: NebulaTab  // 'notes' | 'search' | 'knowledge'

     // Notes state
     notes: NoteListItem[]
     activeNoteId: string | null
     activeNote: NoteFile | null
     isSaving: boolean

     // Search state
     searchQuery: string
     searchResults: SearchResult[]
     isSearching: boolean
     qaAnswer: string
     qaSessionId: string | null

     // Knowledge graph
     graphData: GraphData | null
     selectedGraphNodeId: string | null

     // Voice state
     voiceState: VoiceRecordingState  // 'idle' | 'recording' | 'processing'
     lastTranscript: DiarizedTranscript | null

     // AI state
     isSummarizing: boolean
     summarizeSessionId: string | null
   }
   ```

   Actions:
   - `setActiveTab(tab: NebulaTab)`: Set active tab.
   - `loadNotes()`: Call `window.api.nebula.listNotes()`, update `notes` array.
   - `selectNote(id: string)`: Set `activeNoteId`, call `window.api.nebula.loadNote(id)`, set `activeNote`.
   - `createNote()`: Generate UUID (`crypto.randomUUID()`), create blank NoteFile, call `window.api.nebula.saveNote(...)`, prepend to notes list, select it.
   - `saveNote(note: NoteFile)`: Set `isSaving=true`, call `window.api.nebula.saveNote(note)`, update notes list item, set `isSaving=false`.
   - `deleteNote(id: string)`: Call `window.api.nebula.deleteNote(id)`, remove from notes list, clear activeNote if deleted.
   - `setSearchQuery(query: string)`: Update searchQuery.
   - `searchNotes(query: string)`: Call `window.api.nebula.searchNotes(query)`, set searchResults.
   - `loadGraphData()`: Call `window.api.nebula.getGraph()`, set graphData.
   - `setSelectedGraphNode(id: string | null)`: Update selectedGraphNodeId.
   - `setVoiceState(state: VoiceRecordingState)`: Update voiceState.
   - `setLastTranscript(transcript: DiarizedTranscript | null)`: Update lastTranscript.
   - `setSummarizing(isSummarizing: boolean, sessionId?: string | null)`: Update AI state.
   - `setQaAnswer(answer: string)`: Update qaAnswer.
   - `setQaSessionId(id: string | null)`: Update qaSessionId.
   - `clearActiveNote()`: Set activeNoteId=null, activeNote=null.

   Use `create<NebulaState>()` pattern matching existing stores (launchpad-store.ts, review-store.ts). Export as `useNebulaStore`.

   Note: The IPC calls (window.api.nebula.*) will not exist yet -- that's fine. The store defines the contract. Plan 03 wires IPC. For now, the store compiles because the calls are inside action functions that won't execute until the IPC bridge is connected.
