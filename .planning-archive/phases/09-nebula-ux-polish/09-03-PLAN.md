   - Close on click outside (useEffect with document click listener) or Escape key.

   - A modal overlay dialog for confirming note deletion.
   - Props: `isOpen: boolean`, `noteTitle: string`, `onConfirm: () => void`, `onCancel: () => void`.
   - Overlay: `fixed inset-0 z-50 bg-black/50 flex items-center justify-center`.
   - Dialog card: `bg-surface-elevated border border-border rounded-xl shadow-2xl p-6 max-w-sm w-full`.

   - Close on Escape key. Focus trap on the dialog.

3. Rewrite `NoteList.tsx` — complete overhaul:

   - **Right-click context menu**: `onContextMenu` handler stores mouse position and note id, opens NoteContextMenu.
   - **Duplicate action**: create a new note with the same content and title prefixed with "Copy of ".
   - **Active note highlighting**: selected note has `bg-accent/10 border-l-2 border-accent`.
   - **Notes with drawings**: show a small Pencil icon (lucide) next to the timestamp if `hasDrawing` is true.
   - **Cmd+N keyboard shortcut**: register a global keydown listener for Cmd+N (Meta+n) that creates a new note and returns a signal to focus the title input. Emit a custom event or use a ref callback so NebulaView/NoteEditor can focus the title field.
   - **Create note button**: at top of list, a button with Plus icon and "New Note" text.
   - **Automatic sort**: notes are pre-sorted from store (pinned first, then by updatedAt desc). No manual reorder.

1. **Import react-resizable-panels**: `import { PanelGroup, Panel, PanelResizeHandle } from 'react-resizable-panels'`

2. **Outer layout** (for the Notes tab only — Search and Knowledge tabs remain unchanged):
   - Use a PanelGroup with `direction="horizontal"` and `autoSaveId="nebula-sidebar"` for the sidebar|content split.
   - Left Panel: NoteList sidebar. `defaultSize={22}`, `minSize={5}`, `maxSize={40}`, `collapsible`, `collapsedSize={3}`. Use a ref (`useRef<ImperativePanelHandle>(null)`) to programmatically expand/collapse.
   - PanelResizeHandle: `className="w-1 bg-border hover:bg-accent/30 transition-colors cursor-col-resize"`.
   - Right Panel: the content area (`defaultSize={78}`).

3. **Collapsed sidebar**: When sidebar panel is collapsed (use `onCollapse`/`onExpand` callbacks to track state), render just a vertical expand button (ChevronRight icon) instead of the full NoteList. On click, call `sidebarPanelRef.current?.expand()`.

4. **Inner split** (editor | drawing) inside the content panel:
   - Another PanelGroup with `direction="horizontal"` and `autoSaveId="nebula-editor-split"`.
   - Left Panel: NoteEditor. `defaultSize={100}` (when drawing collapsed), `minSize={30}`.
   - PanelResizeHandle (only rendered when drawing panel is open): `className="w-1.5 bg-border hover:bg-accent/50 transition-colors cursor-col-resize"`.
   - Right Panel: DrawingCanvas. `defaultSize={40}`, `minSize={20}`, `collapsible`, `collapsedSize={0}`. Use a ref for programmatic expand/collapse.

5. **Drawing panel closed by default** for new notes (per user decision):
   - Track `drawingOpen` state. Default to `false`.
   - When drawing panel is collapsed: render a **side rail tab** on the right edge of the content area. This is a small vertical tab (`absolute right-0 top-1/2 -translate-y-1/2 z-10`) labeled "Draw" with a Pencil icon. On click, call `drawingPanelRef.current?.expand()` and set drawingOpen to true.
   - When drawing panel expands via the rail tab, the inner PanelGroup shows both panels.

6. **Double-click divider to reset**: On the inner PanelResizeHandle, add `onDoubleClick` that calls a reset function. Use the panel API: `editorPanelRef.current?.resize(60)` and `drawingPanelRef.current?.resize(40)`.

7. **Global panel size** (per user decision): `autoSaveId` on PanelGroup automatically persists to localStorage, giving consistent panel sizes across all notes.

8. **Smooth animation** (~200ms): When expanding/collapsing, use `style={{ transition: 'flex-basis 200ms ease' }}` on panels — or better, use framer-motion `<motion.div layout>` wrapper around panel content for smooth transitions. Note: react-resizable-panels handles resize smoothly by default; the collapse/expand animation can be achieved with CSS `transition` on the panel's flex.

9. **Remove the old toggle pattern**: Delete the "Show Drawing" / "Hide Drawing" button and the conditional DrawingCanvas rendering. The split-view replaces it entirely.

10. **Modify DrawingCanvas.tsx**:
    - Remove any visibility toggle logic.
    - The component should be always-mounted when the panel is open (react-resizable-panels handles visibility via collapsible).
    - Keep the existing tldraw integration, inferDarkMode, store.listen auto-save, and key={noteId} pattern.
    - Use `tldraw's built-in toolbar` per user decision — no custom overlay. The existing implementation already does this.

11. **Keep Search and Knowledge tabs as-is**: The PanelGroup layout only applies when the Notes tab is active. Search and Knowledge tabs render their existing components without the split panel layout.

12. **Wire Cmd+N**: Listen for the Cmd+N event (from NoteList's global keydown or emit a custom event), create a new note via store, select it, and after a tick, focus the title input in NoteEditor. Use a ref or callback pattern.
