  <action>
Major rewrite of NoteEditor.tsx. Remove the old fixed toolbar completely. Build a Notion-style editing experience.

1. **Tiptap editor configuration** — replace the existing useEditor setup:
   - Extensions: `StarterKit.configure({ heading: { levels: [1, 2, 3] } })`, `Placeholder.configure({ placeholder: 'Start writing...' })`, `Link.configure({ openOnClick: false, autolink: true, defaultProtocol: 'https', HTMLAttributes: { class: 'text-accent underline cursor-pointer' } })`, `Image.configure({ allowBase64: true, inline: false })`, `Table.configure({ resizable: true })`, `TableRow`, `TableCell`, `TableHeader`, and a custom `CustomKeyboardShortcuts` extension.
   - Import Link from `@tiptap/extension-link`, Image from `@tiptap/extension-image`, Table from `@tiptap/extension-table`, TableRow from `@tiptap/extension-table-row`, TableCell from `@tiptap/extension-table-cell`, TableHeader from `@tiptap/extension-table-header`.

2. **CustomKeyboardShortcuts extension** (inline in NoteEditor or separate):
   - `Mod-Shift-1` -> `toggleHeading({ level: 1 })`
   - `Mod-Shift-2` -> `toggleHeading({ level: 2 })`
   - `Mod-Shift-3` -> `toggleHeading({ level: 3 })`
   - `Mod-k` -> set state to open LinkDialog (call a setState callback)
   - StarterKit already provides Mod-b (bold), Mod-i (italic), Mod-z (undo), Mod-Shift-z (redo), Mod-Shift-7 (ordered list), Mod-Shift-8 (bullet list), Mod-e (code).

3. **Seamless inline title**:
   - Replace any separate title input with a large contentEditable div or input styled as: `text-2xl font-bold text-text-primary bg-transparent border-none outline-none w-full placeholder:text-text-secondary/40 mb-1`.
   - Placeholder: "Untitled" in light gray.
   - On Enter key in title: focus the Tiptap editor.
   - Title change triggers the existing debounced save.

4. **Auto-save status dot**:
   - Track save state: 'synced' | 'unsaved' | 'saving' | 'just-saved'.
   - Small 8px rounded-full dot next to the title area. Colors: `bg-text-secondary/30` (synced/gray), `bg-orange-400` (unsaved), `bg-green-400` with brief pulse animation (just-saved — show for 1.5s then back to gray).
   - When content changes: set to 'unsaved'. When save IPC completes: set to 'just-saved', setTimeout to 'synced' after 1.5s.

5. **Metadata line below title**:
   - Small text `text-xs text-text-secondary/60` below the title.
   - Show: last edited time (relative, e.g., "Edited 2 min ago") and word count ("342 words").
   - Word count: count words from editor.getText() or editor.state.doc.textContent.

6. **Topic tags** below metadata:
   - Render as small pills: `bg-accent/10 text-accent text-xs px-2 py-0.5 rounded-full`.
   - For now, display tags from the note's tags array (which may be empty). Include a small "+" button to add a tag (simple text input popup that appends to tags).
   - Tags are stored in the note file's metadata. On tag add/remove, save the note.

7. **Render structure** (top to bottom):
   - Auto-save dot (positioned absolute top-right or inline next to title)
   - Seamless inline title input
   - Metadata line (edited time + word count)
   - Tag pills row
   - Editor content area with `<EditorContent editor={editor} />` (wrapped in `.nebula-editor` div)
   - `<FloatingToolbar editor={editor} onLinkClick={openLinkDialog} />`
   - `<TableControls editor={editor} />` (shown conditionally when cursor in table)
   - `<LinkDialog editor={editor} isOpen={linkDialogOpen} onClose={closeLinkDialog} position={linkPosition} />`

8. **Remove the old toolbar entirely** — no fixed toolbar row with Bold/Italic/H1-H3/UL/OL/Code buttons.

9. **Remove VoiceRecorder from NoteEditor** — it was placed here in Phase 8 but Plan 04 will relocate it as a FAB. Remove the import and rendering of VoiceRecorder from this component. (Plan 04 will add it to NebulaView as a FAB.)

10. **Image paste/drag support**: The `@tiptap/extension-image` with `allowBase64: true` handles paste events and drag-drop automatically. Add a max image size check: in the editor's `editorProps.handleDrop` and `editorProps.handlePaste`, check file size < 5MB, reject with console.warn if too large.
