### Task 1: Flow Utilities, Custom Node, Custom Edge Components

**Files:** `flow-utils.ts`, `FlowNode.tsx`, `FlowEdge.tsx`, `flow-styles.css`

**flow-utils.ts** — Layout engine and data transformation utilities:

```typescript
import dagre from '@dagrejs/dagre'
import type { Node, Edge } from '@xyflow/react'
import type { CodeEntity, CallEdge, ComponentInfo, PipelineInfo, FlowNodeData, FlowEdgeData } from '../../../../types/codebase-analyzer'
```

Functions to implement:

1. **`layoutGraph(nodes: Node[], edges: Edge[], direction: 'TB' | 'LR' = 'LR'): { nodes: Node[]; edges: Edge[] }`**
   - Create dagre graph with `rankdir: direction`, `nodesep: 60`, `ranksep: 120`
   - Set each node with `width: 220, height: 80`
   - Run `dagre.layout(g)`
   - Map positions back to React Flow nodes (center offset: `x - 110, y - 40`)

2. **`buildAPIFlowNodes(entities: CodeEntity[], calls: CallEdge[], routes: RouteInfo[]): { nodes: Node<FlowNodeData>[]; edges: Edge<FlowEdgeData>[] }`**
   - For each route/endpoint, trace the call chain: Controller → Service → Repository → Database
   - Create nodes with type mapping: 'controller'=blue, 'service'=green, 'repository'=amber, 'middleware'=purple
   - Add a virtual "Database" node at the end of chains that reach repository entities
   - Create edges with animated=true for the main flow
   - Icon mapping: controller→'Globe', service→'Cog', repository→'Database', middleware→'Shield', database→'HardDrive'
   - Limit to max 150 nodes. If more, group by controller and show collapsed view.

3. **`buildComponentTreeNodes(components: ComponentInfo[]): { nodes: Node<FlowNodeData>[]; edges: Edge<FlowEdgeData>[] }`**
   - Start from the root component (App or first component with no parent)
   - Create nodes for each component with kind='component', icon='Component'
   - Create parent→child edges based on `ComponentInfo.children` matching component names
   - Color: route components=blue, layout components=green, leaf components=gray

4. **`buildPipelineNodes(pipelines: PipelineInfo[]): { nodes: Node<FlowNodeData>[]; edges: Edge<FlowEdgeData>[] }`**
   - Create nodes for each DAG task/pipeline step
   - Create edges from `PipelineInfo.dependencies` (upstream → downstream)
   - Icon: dag→'Workflow', task→'Play', model→'Table'

5. **`getStageColor(type: FlowNodeType): { bg: string; border: string; text: string; glow: string }`**
   - Return oklch color values for each stage type, following the UI_UX.md STAGE_COLORS pattern:
     - controller: blue (oklch(70% 0.15 250))
     - service: green (oklch(72% 0.17 142))
     - repository: amber (oklch(75% 0.15 85))
     - database: red (oklch(65% 0.2 25))
     - middleware: purple (oklch(70% 0.15 300))
     - component: cyan (oklch(72% 0.15 195))
     - dag/task: orange (oklch(72% 0.15 55))
     - model: teal (oklch(70% 0.15 175))

```
| Summary text (2 lines max)       |

```


Implementation:
- Register custom node types: `const nodeTypes = useMemo(() => ({ codeEntity: FlowNodeComponent }), [])` — MUST be memoized or defined outside component

- On mount, run `layoutGraph(props.nodes, props.edges, direction)` to compute positions
- Use `useNodesState` and `useEdgesState` hooks from React Flow for internal state
- Wrap in a container div with `className="cban-flow h-full w-full rounded-xl border border-border bg-background"`
- CRITICAL: Parent container MUST have explicit height. Use `className="h-full"` on all parents up the chain.

