**RepoManager.tsx** — Repository management panel. Shows repo cards grid + "Add Repository" button.

```typescript
import { Plus, FolderGit2, Trash2, RefreshCw } from 'lucide-react'
import { motion } from 'framer-motion'
```

Layout:
- Header row: "Repositories" title + "Add Repository" button (Plus icon, `bg-accent/15 text-accent hover:bg-accent/25 rounded-lg px-3 py-1.5 text-xs font-medium`)
- Grid: `className="grid grid-cols-1 gap-4 sm:grid-cols-2 xl:grid-cols-3 p-6"`
- Each repo rendered as `<RepoCard>`
- Empty state when no repos: centered illustration with "Add your first repository to get started" text and large "Add Repository" button

When "Add Repository" is clicked, show `<AddRepoDialog>` as a modal overlay.

When a repo card's "Analyze" button is clicked:
1. Set `isAnalyzing: true` via store
2. Set up progress listener: `window.api.cban.onAnalysisProgress(data => store.setProgress(data))`
3. Call `window.api.cban.analyze(repo.repoPath, repo.branch, repo.url)`
4. On success: `store.setAnalysisResult(result)`, `store.updateRepo(id, { status: 'ready', lastAnalyzed: new Date().toISOString() })`, auto-switch to insights tab
5. On error: `store.updateRepo(id, { status: 'error', error: err.message })`
6. Finally: `store.setIsAnalyzing(false)`, `window.api.cban.removeProgressListeners()`

Use `motion.div` wrapper with `initial={{ opacity: 0, y: 12 }}` and staggered animation: `transition={{ delay: index * 0.08 }}`.

**AddRepoDialog.tsx** — Modal dialog for adding a new repository.

Renders as a fixed overlay: `className="fixed inset-0 z-50 flex items-center justify-center bg-background/80 backdrop-blur-sm"`

Inner modal: `className="w-[520px] rounded-xl border border-border bg-surface p-6 shadow-2xl"`

Fields:
1. **Repository URL** — text input. Validate: must start with `https://` or `git@`. On blur, auto-extract repo name from URL.
2. **Branch** — dropdown/select. When URL is entered and valid, call `window.api.cban.fetchBranches(url)` to populate. Show loading spinner while fetching. Default to `main` or `master` (first match).
3. **Repository Name** — text input, auto-filled from URL but editable. Used as the local directory name.

Buttons: "Cancel" (ghost) + "Add & Clone" (primary: `bg-accent/15 text-accent hover:bg-accent/25`)

On submit:
1. Generate UUID for repo ID
2. Create `Repository` object with status='cloning'
3. Add to store, close dialog
4. Set up clone progress listener: `window.api.cban.onCloneProgress(data => store.updateRepo(id, { ... }))`
5. Call `window.api.cban.clone(url, name)`
6. On success: update repo with `repoPath`, status='idle'
7. On error: update repo with status='error', error message
8. Clean up progress listener

Handle auth errors gracefully: if clone fails with auth error, show a banner suggesting the user configure git credentials or use SSH.
