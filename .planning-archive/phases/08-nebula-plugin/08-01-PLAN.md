<task type="auto">
  <name>Task 2: Build SQLite database manager and file storage</name>
  <files>
    src/main/nebula/database.ts

  </files>
  <action>
1. Create `src/main/nebula/database.ts` — NebulaDatabase class:
   - Constructor takes optional `storagePath` string. Default DB path: `path.join(app.getPath('userData'), 'nebula.db')`. If storagePath provided: `path.join(storagePath, 'nebula.db')`.
   - Set pragmas: `journal_mode = WAL`, `foreign_keys = ON`.
   - `initSchema()` creates tables:
     - `notes` (id TEXT PK, title TEXT NOT NULL DEFAULT 'Untitled', content TEXT NOT NULL DEFAULT '{}', drawing TEXT, summary TEXT, topics TEXT DEFAULT '[]', created_at TEXT DEFAULT datetime('now'), updated_at TEXT DEFAULT datetime('now'))
     - `notes_fts` FTS5 virtual table with external content: `CREATE VIRTUAL TABLE IF NOT EXISTS notes_fts USING fts5(title, summary, content_text, content='notes', content_rowid='rowid')`
     - `graph_edges` (id INTEGER PK AUTOINCREMENT, source_id TEXT NOT NULL REFERENCES notes(id) ON DELETE CASCADE, target_id TEXT NOT NULL REFERENCES notes(id) ON DELETE CASCADE, relationship TEXT DEFAULT 'related', weight REAL DEFAULT 1.0, UNIQUE(source_id, target_id))
     - `transcriptions` (id TEXT PK, note_id TEXT REFERENCES notes(id) ON DELETE SET NULL, audio_path TEXT NOT NULL, transcript TEXT NOT NULL, speakers TEXT, created_at TEXT DEFAULT datetime('now'))
   - CRUD methods (all synchronous, better-sqlite3 is sync):
     - `upsertNote(note: { id, title, contentText, summary, topics })`: INSERT OR REPLACE into notes, then manually DELETE from notes_fts WHERE rowid = (notes rowid) and INSERT into notes_fts
     - `getNote(id: string)`: SELECT from notes
     - `deleteNote(id: string)`: DELETE from notes_fts first (get rowid), then DELETE from notes (CASCADE handles graph_edges)
     - `listNotes()`: SELECT id, title, summary, updated_at FROM notes ORDER BY updated_at DESC
   - FTS search: `searchNotes(query: string)`: Use `notes_fts MATCH ?` with `highlight()` and `bm25()` ranking, JOIN back to notes for full data, LIMIT 20
   - Graph methods:
     - `upsertEdges(sourceId: string, targets: { targetId: string, relationship: string, weight: number }[])`: DELETE existing edges for sourceId, INSERT new ones. Wrap in transaction.
     - `getGraphData()`: Returns { nodes: [{id, name (title), val (connection count)}], links: [{source, target, label (relationship)}] }
   - Transcription methods:
     - `saveTranscription(record: { id, noteId, audioPath, transcript, speakers })`: INSERT into transcriptions
     - `getTranscriptionsByNote(noteId: string)`: SELECT from transcriptions WHERE note_id = ?
   - `close()`: Close database connection.

2. Create `src/main/nebula/file-storage.ts` — NoteFileStorage class:
   - Constructor takes `storagePath: string` (base directory for notes). Creates `{storagePath}/notes/` subdirectory if it doesn't exist using `fs.mkdirSync({ recursive: true })`.
   - `writeNote(note: NoteFile)`: Write JSON to `{storagePath}/notes/{note.id}.json` using `fs.writeFileSync` with pretty-print (2-space indent). Use a duplicate type (no renderer imports) for the note shape: `{ id, title, content, drawing, summary, topics, createdAt, updatedAt }`.
   - `readNote(id: string)`: Read and parse JSON from `{storagePath}/notes/{id}.json`. Return null if file doesn't exist.
   - `deleteNote(id: string)`: Remove `{storagePath}/notes/{id}.json`. Ignore if file doesn't exist.
   - `listNoteFiles()`: Read directory, filter for .json files, return array of ids (filename without extension).
   - `extractPlainText(tiptapJson: object)`: Recursively walk Tiptap JSON to extract plain text content (traverse `content` arrays, collect `text` fields). This plain text is what gets indexed in FTS5.

   IMPORTANT: Do NOT import renderer types. Duplicate the note shape interface locally in the main process file (same fields as NoteFile type but declared independently to avoid cross-process imports).
  </action>
