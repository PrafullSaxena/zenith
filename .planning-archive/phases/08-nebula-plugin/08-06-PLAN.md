1. Add AI Q&A action to `src/renderer/src/stores/nebula-store.ts`:

   Add `askQuestion(question: string)` action:
   - First, search for relevant notes: call `window.api.nebula.searchNotes(question)` to get top matching notes.
   - Build a context string from the search results: concatenate title + summary for each result (top 5).
   - Define a Q&A system prompt:
     ```
     const QA_SYSTEM_PROMPT = `You are a knowledgeable assistant. Answer the user's question using ONLY the provided note summaries as context. If the notes don't contain relevant information, say so. Be concise and cite which notes your answer is based on.`
     ```
   - User prompt: `"Context from notes:\n\n${contextString}\n\nQuestion: ${question}"`
   - Set up session-scoped IPC listeners (same pattern as summarization):
     - `onStreamChunk`: accumulate into qaAnswer (set with `setQaAnswer(accumulated)`).
     - `onStreamDone`: Clean up listeners.
     - `onStreamError`: Set error message, clean up.
   - Call `window.api.ai.startAnalysis(providerId, modelName, QA_SYSTEM_PROMPT, userPrompt, sessionId)`.
   - Set `qaSessionId`, clear previous `qaAnswer`.

   Add `cancelQa()` action: Call `window.api.ai.cancelAnalysis(qaSessionId)` if sessionId exists, clean up listeners.

2. Create `src/renderer/src/plugins/nebula/SearchView.tsx`:
   - Import `useNebulaStore` for searchQuery, setSearchQuery, searchResults, searchNotes, selectNote, setActiveTab, qaAnswer, askQuestion, cancelQa, isSearching.
   - Import `Search, MessageCircleQuestion, FileText, Loader2` from lucide-react.

   Layout (full height, two sections):

   **Top section: Full-text search**
   - Search input: `<input>` with Search icon, placeholder "Search notes...", `bg-surface-elevated border border-border rounded-lg px-3 py-2`.
   - On input change: call `setSearchQuery(value)`. Debounce 300ms, then call `searchNotes(value)`.
   - Results list below input: Map over `searchResults`:
     - Each result card: `bg-surface-elevated rounded-lg p-3 hover:bg-surface-hover cursor-pointer border border-border/50`.
     - Show title (use `titleHighlight` with `<mark>` tags if available, fall back to plain title). Render highlights using `dangerouslySetInnerHTML` (the highlights come from SQLite FTS5 `highlight()` function with `<mark>` tags -- safe since it's from our own SQLite, not user input).
     - Show summary highlight or plain summary (truncated to 2 lines).
     - Show `updatedAt` as relative time.
     - On click: call `selectNote(result.id)` then `setActiveTab('notes')`.
   - Empty state: "No results found" when query is non-empty and results are empty.
   - Initial state: "Search your notes by keyword or phrase" when query is empty.

   **Bottom section: AI Q&A**
   - Separator with "Ask your notes" heading and MessageCircleQuestion icon.
   - Question input: `<input>` with placeholder "Ask a question about your notes...". Submit button (or Enter key).
   - On submit: call `askQuestion(questionText)`.
   - Response area: Display `qaAnswer` as streaming text. Use the same MarkdownRenderer component used elsewhere in the app (import from `../../components/MarkdownRenderer`). Show Loader2 spinner while answer is streaming (qaAnswer is accumulating and qaSessionId is set).
   - Cancel button: When streaming, show a cancel button that calls `cancelQa()`.
   - Empty state: "Ask anything about your notes. AI will search your knowledge base and provide an answer." when no question asked yet.

   Styling: The two sections should be in a scrollable container. Search section takes up top ~50%, Q&A section takes bottom ~50%. Use a `flex flex-col gap-4 p-4 h-full overflow-y-auto` layout.
