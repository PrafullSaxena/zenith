1. Update `src/main/ipc-handlers.ts`:
   - Import NebulaDatabase and NoteFileStorage from `./nebula/database` and `./nebula/file-storage`.
   - Import `app` from electron (already imported), `path`, `fs` from node.
   - At module level (alongside tokenManager and dbManager), create lazy-initialized nebula instances:
     ```
     let nebulaDb: NebulaDatabase | null = null
     let nebulaFs: NoteFileStorage | null = null

     function getNebulaInstances(): { db: NebulaDatabase, fs: NoteFileStorage } {
       if (!nebulaDb || !nebulaFs) {
         const storagePath = (getSetting('plugins.nebula.storagePath') as string) || app.getPath('userData')
         nebulaDb = new NebulaDatabase(storagePath)
         nebulaFs = new NoteFileStorage(storagePath)
       }
       return { db: nebulaDb, fs: nebulaFs }
     }
     ```

   - Register these IPC handlers inside `registerIpcHandlers()`:

     `nebula:saveNote` (handle): Accepts note object { id, title, content, drawing, summary, topics, createdAt, updatedAt }. Calls `nebulaFs.writeNote(note)`, then `nebulaDb.upsertNote({ id, title, contentText: nebulaFs.extractPlainText(note.content), summary, topics })`. Returns `{ saved: true }`.

     `nebula:loadNote` (handle): Accepts id string. Returns `nebulaFs.readNote(id)`.

     `nebula:listNotes` (handle): Returns `nebulaDb.listNotes()`.

     `nebula:deleteNote` (handle): Accepts id string. Calls `nebulaDb.deleteNote(id)`, then `nebulaFs.deleteNote(id)`.

     `nebula:searchNotes` (handle): Accepts query string. Returns `nebulaDb.searchNotes(query)`.

     `nebula:getGraph` (handle): Returns `nebulaDb.getGraphData()`.

     `nebula:updateEdges` (handle): Accepts sourceId and targets array. Calls `nebulaDb.upsertEdges(sourceId, targets)`.

     `nebula:transcribeAudio` (handle): Accepts audioBuffer (number[]). Writes to temp file, calls OpenAI transcription (to be implemented in Plan 05), returns transcript. For now, create stub that throws "Transcription not yet configured".

     `nebula:selectAudioFile` (handle): Uses `dialog.showOpenDialog` with audio file filters (`['mp3','wav','m4a','webm','ogg']`). Returns `{ canceled, path }`.

   All handlers should use `getNebulaInstances()` to get db/fs references (lazy init).
