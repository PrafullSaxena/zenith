# Plan 14-03: Architecture Dashboard Static Diagrams

## Goal
The Architecture Dashboard currently shows NOTHING unless AI insights are generated (which requires a configured AI agent). It should show meaningful static diagrams built from the analysis data (entities, calls, routes) even without any AI agent configured.

## Root Cause Analysis

`ArchitectureDashboard.tsx` has this control flow:
1. No `analysisResult` → "No analysis data available"
2. No `aiInsights` AND not generating → Shows "Generate Architecture Insights" button
3. Generating → Shows spinner
4. Has `aiInsights` → Shows full dashboard

**Problem:** Step 2 blocks the entire dashboard behind AI. A user with no AI agent configured can NEVER see any architecture visualization. The button does nothing because `generateInsights()` returns early when `getCortexAgent()` is null.

## Tasks

<task id="1">
**Add static analysis section that renders WITHOUT AI insights**

Restructure `ArchitectureDashboard.tsx` so the component always shows useful data from `analysisResult` when available:

**Section A (always shown): Code Structure Overview**
Build directly from `analysisResult` (no AI needed):
- Entity breakdown by kind (controller, service, repository, etc.) as colored badges with counts
- API endpoint count
- File count and line count stats
- Framework and language badges

**Section B (always shown): Entity Relationship Diagram**
Build a React Flow graph from `analysisResult.entities` and `analysisResult.calls`:
- Group entities by kind into layers (controllers → services → repositories)
- Draw call edges between them
- Use the same `KIND_COLORS` map already defined in the file
- This replaces the current entity graph that only shows when `aiInsights.entities` exist

**Section C (AI-powered, optional): AI Architecture Insights**
Keep the existing AI-powered cards (dependencies, security, patterns, etc.) but:
- Show them in a collapsible section titled "AI-Powered Insights"
- Show the "Generate" button inline within this section, not blocking the whole page
- If no agent configured, show a subtle note "Configure an AI agent in Settings to unlock deeper insights"
</task>

<task id="2">
**Build entity graph from analysisResult**

Create a helper function `buildStaticEntityGraph(analysisResult)` that:
- Takes `analysisResult.entities` and `analysisResult.calls`
- Groups entities by kind
- Places controller nodes on the left, services in the middle, repositories on the right
- Draws call edges between connected entities
- Limits to top 30 entities to keep it readable
- Returns `{ nodes: Node[], edges: Edge[] }` compatible with ReactFlow

This is similar to the existing `buildEntityGraph(insights)` but uses raw analysis data instead of TOON-parsed AI insights.
</task>

<task id="3">
**Build route summary from analysisResult**

Show a mini API summary directly from `analysisResult.routes`:
- Count by HTTP method (GET: N, POST: N, etc.)
- Show top 10 routes as a compact list
- Each route clickable to navigate to the handler file
</task>
