**src/main/bitbucket/oauth.ts** -- OAuth 2.0 authorization code grant via BrowserWindow:

- Export `startOAuthFlow(clientId: string, clientSecret: string): Promise<BitbucketTokenPair>`
- Create a BrowserWindow popup (800x600, nodeIntegration=false, contextIsolation=true) with `parent` set to the BrowserWindow passed as parameter or fetched via `BrowserWindow.getFocusedWindow()`
- Build auth URL: `https://bitbucket.org/site/oauth2/authorize?client_id=${clientId}&response_type=code&redirect_uri=${encodeURIComponent(REDIRECT_URI)}`
- `REDIRECT_URI = 'http://127.0.0.1/oauth/bitbucket/callback'` (loopback, no local server needed)
- Use `authWindow.webContents.session.webRequest.onBeforeRequest` with filter `{ urls: ['http://127.0.0.1/oauth/bitbucket/callback*'] }` to intercept redirect
- Extract `code` from URL searchParams, cancel the request, close the window
- Call `exchangeCodeForTokens(code, clientId, clientSecret)` -- POST to `https://bitbucket.org/site/oauth2/access_token` with `grant_type=authorization_code`, Basic auth header (`Buffer.from(clientId:clientSecret).toString('base64')`)
- Content-Type: `application/x-www-form-urlencoded`, body as URLSearchParams
- Handle `authWindow.on('closed')` to reject promise if user closes manually
- Call `authWindow.focus()` after creation to ensure visibility

**src/main/bitbucket/token-manager.ts** -- Token lifecycle with auto-refresh:

- Export class `TokenManager` with methods:
  - `constructor()` -- loads stored tokens from safeStorage on instantiation
  - `storeTokens(tokens: BitbucketTokenPair, clientId: string, clientSecret: string): void` -- encrypt and store via safeStorage in credentials store (key: `'bitbucket-tokens'`). Calculate `expiresAt = Date.now() + tokens.expires_in * 1000`
  - `getAccessToken(): Promise<string>` -- if `expiresAt - Date.now() < 5 * 60 * 1000` (5 min buffer), auto-refresh first. Return current access token. Throw if no tokens stored.
  - `refreshTokens(): Promise<void>` -- POST to `https://bitbucket.org/site/oauth2/access_token` with `grant_type=refresh_token`. Update stored tokens.
  - `clearTokens(): void` -- remove from credentials store
  - `hasTokens(): boolean` -- check if tokens exist
  - `isConnected(): boolean` -- hasTokens() AND not expired
- Use `safeStorage.encryptString` / `safeStorage.decryptString` for token persistence
- Use the separate credentials electron-store instance (import pattern from `ipc-handlers.ts`: `new Store({ name: 'zenith-credentials' })`)
- Import `safeStorage` from `electron`

**src/main/bitbucket/api.ts** -- Bitbucket REST API v2.0 client:

- `const BB_API = 'https://api.bitbucket.org/2.0'`
- Export `listOpenPRs(workspace: string, repoSlug: string, accessToken: string): Promise<BitbucketPR[]>` -- GET `/repositories/{workspace}/{repoSlug}/pullrequests?state=OPEN`. Return `data.values`. Handle pagination if `next` exists (fetch all pages).
- Export `getPRDiff(workspace: string, repoSlug: string, prId: number, accessToken: string): Promise<string>` -- GET `/repositories/{workspace}/{repoSlug}/pullrequests/{prId}/diff`. Return raw text (unified diff format).
- Export `postInlineComment(workspace: string, repoSlug: string, prId: number, accessToken: string, filePath: string, line: number, comment: string): Promise<void>` -- POST `/repositories/{workspace}/{repoSlug}/pullrequests/{prId}/comments` with body `{ content: { raw: comment }, inline: { path: filePath, to: line } }`. Use `to` for new/modified lines per research findings. Authorization header: `Bearer ${accessToken}`.
- All functions use native `fetch()` (available in Electron main process).
