Create module-level `tokenManager = new TokenManager()`.

Add these handlers inside `registerIpcHandlers()`:

**Bitbucket channels:**
- `bitbucket:connect` -- Read clientId and clientSecret from settings (`plugins.code-review-bot.bitbucketClientId` and `plugins.code-review-bot.bitbucketClientSecret`). If not set, throw error. Call `startOAuthFlow(clientId, clientSecret)`. On success, store tokens via `tokenManager.storeTokens(tokens, clientId, clientSecret)`. Return `{ connected: true }`.
- `bitbucket:disconnect` -- Call `tokenManager.clearTokens()`. Return `{ connected: false }`.
- `bitbucket:isConnected` -- Return `tokenManager.isConnected()`.
- `bitbucket:listPRs` -- Args: `(workspace: string, repoSlug: string)`. Get token via `tokenManager.getAccessToken()`. Call `listOpenPRs(workspace, repoSlug, token)`. Return PR array.
- `bitbucket:getPRDiff` -- Args: `(workspace: string, repoSlug: string, prId: number)`. Get token, call `getPRDiff(...)`. Return raw diff string.
- `bitbucket:postComment` -- Args: `(workspace: string, repoSlug: string, prId: number, filePath: string, line: number, comment: string)`. Get token, call `postInlineComment(...)`.

**AI channels:**
- `ai:startReview` -- Args: `(providerId: string, modelName: string, diff: string, sessionId: string)`. Get the focused BrowserWindow via `BrowserWindow.getFocusedWindow()` or first window. Call `streamReview({ mainWindow, diff, providerId, modelName, sessionId })`. Return `{ started: true, sessionId }`.
- `ai:cancelReview` -- Args: `(sessionId: string)`. Call `cancelReview(sessionId)`.

  cancelReview: (sessionId: string) =>
    ipcRenderer.invoke('ai:cancelReview', sessionId),

**src/renderer/src/stores/review-store.ts** -- Zustand store:

Create the store following the same pattern as activity-store.ts (optimistic update + IPC persistence):

```typescript
interface ReviewStoreState {
  // Connection state
  isConnected: boolean
  isConnecting: boolean

  // PR browsing
  pullRequests: PullRequest[]
  isLoadingPRs: boolean
  selectedPR: PullRequest | null

  // Diff state
  rawDiff: string
  diffFiles: DiffFile[]
  isLoadingDiff: boolean

  // Active review session
  currentSession: ReviewSession | null

  // Review history
  history: ReviewHistoryEntry[]
  isLoadingHistory: boolean

  // Actions
  connect: () => Promise<void>
  disconnect: () => Promise<void>
  checkConnection: () => Promise<void>
  loadPRs: (workspace: string, repoSlug: string) => Promise<void>
  selectPR: (pr: PullRequest) => void
  loadDiff: (workspace: string, repoSlug: string, prId: number) => Promise<void>
  startReview: (providerId: string, modelName: string) => Promise<void>
  cancelReview: () => void
  postComment: (workspace: string, repoSlug: string, prId: number, comment: ReviewComment) => Promise<void>
  postAllComments: (workspace: string, repoSlug: string, prId: number) => Promise<void>
  loadHistory: () => Promise<void>
  addHistoryEntry: (entry: Omit<ReviewHistoryEntry, 'id' | 'timestamp'>) => Promise<void>
}
```

Key implementation details:

- `connect()`: Set isConnecting=true, call `window.api.bitbucket.connect()`, set isConnected on success, isConnecting=false.
- `disconnect()`: Call `window.api.bitbucket.disconnect()`, reset isConnected.
- `checkConnection()`: Call `window.api.bitbucket.isConnected()`, update isConnected.
- `loadPRs()`: Call `window.api.bitbucket.listPRs()`, set pullRequests.
- `loadDiff()`: Call `window.api.bitbucket.getPRDiff()`, parse with `parseDiff` from `parse-diff` package, set rawDiff and diffFiles.
- `startReview()`: Generate sessionId (`review-${Date.now()}`). Create ReviewSession with status='streaming'. Call `window.api.ai.startReview(providerId, modelName, rawDiff, sessionId)`. Set up IPC listeners (onStreamChunk accumulates rawText, onStreamDone sets status='complete' and parses comments from rawText, onStreamError sets status='error').
- `cancelReview()`: Call `window.api.ai.cancelReview(sessionId)`, set status='cancelled', call `window.api.ai.removeStreamListeners()`.
- `postComment()`: Call `window.api.bitbucket.postComment(...)`, mark comment as posted=true in currentSession.comments.
- `postAllComments()`: Iterate currentSession.comments, call postComment for each, track posted count.
- `loadHistory()`: Load from `window.api.settings.get('reviewHistory')`.
- `addHistoryEntry()`: Generate id (`rev-${Date.now()}-${random}`), prepend to history, persist via `window.api.settings.set('reviewHistory', updated)`. Cap at 100 entries.

**Critical:** The `startReview` action must set up IPC listeners and clean them up when streaming completes or errors. Use `window.api.ai.onStreamChunk` / `onStreamDone` / `onStreamError` and call `window.api.ai.removeStreamListeners()` in the done/error/cancel handlers.

**Comment parsing:** After streaming completes (onStreamDone), parse `rawText` for JSON objects line-by-line. Each line matching `{"file":...}` pattern should be parsed as a ReviewComment. Non-JSON lines are treated as summary text.
