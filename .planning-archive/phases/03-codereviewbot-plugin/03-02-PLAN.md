  <action>
Create `src/main/ai/stream.ts` that orchestrates AI code review streaming.

Maintain an in-memory `Map<string, AbortController>` for active review sessions (keyed by sessionId).

Export `streamReview(params: { mainWindow: BrowserWindow; diff: string; providerId: string; modelName: string; sessionId: string }): Promise<void>`:

1. Create an `AbortController` and store it in the sessions map with `sessionId` as key.
2. Resolve API key via `getApiKeyForProvider(providerId)` from providers.ts.
3. Create model via `createModel(providerId, modelName, apiKey)`.
4. Call `streamText()` from `'ai'` package:
   ```typescript
   const { textStream } = streamText({
     model,
     system: `You are a senior code reviewer. Analyze the following unified diff and provide a structured code review.

For each issue found, output a JSON object on its own line with this format:
{"file": "path/to/file", "line": number, "severity": "critical"|"warning"|"suggestion", "comment": "description"}

After all file-specific comments, provide a brief overall summary.

Be concise. Focus on bugs, security issues, performance problems, and code quality.`,
     prompt: diff,
     abortSignal: controller.signal,
   })
   ```
5. Iterate the `textStream` async iterable: for each `chunk`, call `mainWindow.webContents.send('ai:stream:chunk', { sessionId, chunk })`.
6. After iteration completes: `mainWindow.webContents.send('ai:stream:done', { sessionId })`.
7. Wrap in try/catch: on error, send `mainWindow.webContents.send('ai:stream:error', { sessionId, error: err.message })`.
8. In finally block: remove the AbortController from the sessions map.

Export `cancelReview(sessionId: string): void`:
- Look up AbortController in sessions map
- Call `controller.abort()` if found
- Remove from map

Import `BrowserWindow` from `'electron'`, `streamText` from `'ai'`, `createModel` and `getApiKeyForProvider` from `'./providers'`.
